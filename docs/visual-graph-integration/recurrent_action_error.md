# 기존 앞단의 Graph 입력과 GT 입력에 따른 Mamba 행동 오차

[새 앞단으로 Mamba를 처음 재학습한 실험](recurrent_new_frontend.md)의 Mamba 5개 앙상블을 사용했다. 여기서 Graph는 전체 삽입 구간을 추가하기 전 **954에폭 Transformer와 54에폭 GNN**의 출력이다. [후속 앞단](full_insertion_frontend.md)의 가중치는 사용하지 않았다. Recurrent 필터는 우회했다.

## Expert 관측에서의 입력 비교

Mamba 학습 시 가중치 업데이트에는 쓰이지 않았고 체크포인트를 선택할 때 사용한 성공 Expert 검증 데모 21개(고정 11개, 실제 이동 10개, 총 2,551프레임)를 분석했다. 에피소드마다 초기 상태부터 실제 로봇 상태와 Graph Object21을 주는 경우와 같은 로봇 상태에 GT Object21을 주는 경우를 독립적으로 재생했다. 각 조건에서 Mamba 상태를 초기화하고 동일 종류의 입력을 끝까지 유지했다. 예측 행동을 환경에 적용하지 않았기 때문에 두 조건의 로봇 관측과 비교할 Expert Action7이 같다.

이동 명령에 컨트롤러의 클리핑과 스케일(정규화 명령 단위당 100 mm)을 적용해 Expert 명령과 비교했다. 삽입축 및 횡방향 분해에는 GT Hole 회전을 사용했다. 단위는 실제 이동 거리가 아닌 스텝당 TCP 위치 명령 차이의 mm다.

| Expert 구간 | 프레임 | 전체 이동 오차 P90, GT → Graph | 삽입축 오차 P90, GT → Graph | 횡방향 오차 P90, GT → Graph |
| --- | ---: | ---: | ---: | ---: |
| 전체 | 2,551 | 2.04 → 2.86 mm | 1.41 → 1.74 mm | 1.19 → 1.71 mm |
| 모든 Box 삽입 단계 | 360 | 3.78 → 5.90 mm | 3.71 → 5.77 mm | 0.70 → 1.39 mm |
| 이동 Box 정렬 단계 | 412 | 2.89 → 3.93 mm | 2.27 → 3.33 mm | 1.89 → 2.24 mm |
| 이동 Box 삽입 단계 | 160 | 3.79 → 5.52 mm | 3.72 → 5.29 mm | 0.70 → 1.37 mm |
| 이동 Box 깊이 20 mm 초과 | 88 | 0.59 → 0.89 mm | 0.42 → 0.69 mm | 0.52 → 0.81 mm |

이동 Box의 삽입 단계에서 GT와 Graph 모두 그리퍼 열기/닫기를 Expert와 일치시켰다. Graph 입력에서는 Expert 행동과의 이동 차이가 전반적으로 컸고, 이동 Box 삽입 단계의 전체 이동 오차는 삽입축 차이가 대부분이었다. 기존 파인튜닝은 에피소드별로 하나의 혼합 계수를 선택했고, 검증 체크포인트 선택은 Graph 입력을 써서 진행했다. 이 비교에서 GT는 입력 위치 추정 품질에 따른 행동 민감도를 확인하는 대조군이다.

## 실제로 얕게 진입한 후 정체한 롤아웃

[이동 Box 실패 21개 분석](recurrent_moving_box_failure_analysis.md)에서 얕게 진입한 11개를 확인했다. 각 시드 마지막 20프레임의 명령 및 상태 중앙값을 구한 뒤 시드 사이의 중앙값을 산출했다. 모든 시드에서 Box가 이미 멈췄고 Peg를 쥐고 있었다.

- 11개 모두 삽입축의 정방향 이동 명령을 냈다. 장면별 정방향 명령 중앙값을 다시 집계하면 약 10.0 mm/스텝이다. 같은 20프레임 사이 실제 깊이의 최대–최소 범위 중앙값은 0.13 mm였다.
- 11개 중 6개는 그 구간의 횡방향 이동 명령 중앙값이 실제 Peg 끝점 이탈을 줄이는 방향의 반대였다. 평행이동 명령을 구멍 축에 투영한 결과이며, 회전 명령으로 인한 Peg 끝의 이동이나 실제 접촉력은 반영하지 않는다.
- 700674는 삽입축 명령 11.14 mm/스텝, 옆으로 벗어난 실제 거리 18.64 mm, GNN 횡방향 오차 1.36 mm였다. 그 시간대의 실제 깊이 변화량은 +0.02 mm였다.

실패 상태에서 실행됐을 Expert 행동은 로그에 없다. 따라서 이 구간에서는 실제 명령이 입구 정체와 어떻게 함께 나타났는지 확인했고, Expert 명령과의 수치 비교는 위 검증 데모에서 수행했다. Graph만 넣을 때 Expert 모방 오차가 커진다는 관찰은 입력 차이가 영향을 준다는 근거지만, GT를 섞어 훈련한 선택 자체가 실패를 유발했는지는 Graph 전용으로 다시 학습한 정책과 대조해야 확인할 수 있다.

RTX 3090에서 Expert 행동 예측을 실행했고, 한 검증 시퀀스에서 일괄 추론을 실제 스텝별 앙상블과 대조했다. 폐루프 정체 구간은 이전 롤아웃에서 산출했다.
