# 이동 Box를 포함한 시뮬레이터 GT20 GNN 학습

## 실험 설정

[고정 Box GT20 학습](gt20_object21_retraining.md)과 같은 그래프, GNN 구조, GT Object21 정답, 손실 및 AdamW 설정을 사용했다. 입력은 Simulator의 Peg 꼭짓점 8개, Box 외곽 8개, 앞쪽 Hole 꼭짓점 4개와 TCP다. 검출·추적 결과 및 이미지가 GNN 입력에 들어가지 않는다.

Box가 움직이는 궤적은 기존 `EpisodeHoleMotion`으로 생성했다. scripted expert가 물체를 잡고 정렬 단계에 처음 들어갈 때부터 Box 전체가 수평으로 직선 이동한다. 에피소드마다 이동 방향과 목표 거리 60–120 mm, 이동 시간 0.8–1.4초를 무작위로 정했다. Peg 끝점이 80 mm 이내에 있거나 이동 경로가 해당 영역을 통과하면 이동을 정지한다. 수집은 expert의 삽입 단계 진입 또는 200스텝에 끝냈다. 실제 이동량과 이동 여부는 매 프레임 기록했다. 이동 직후 GT Box·Hole 상태와 관측을 갱신했고, GT Hole 위치 변화와 기록한 이동량이 2 µm 이내에서 일치하는지 검사했다.

기존 고정 데이터의 시드 176개(3100000–3100175)를 이동 조건에서도 재사용했다. 시드별 초기 GT 20점, TCP, Object21이 일치했다. 분할 경계는 기존과 같고, 새 모델은 기존 학습 시드 120개 중 홀수 시드 60개의 고정 궤적과 짝수 시드 60개의 이동 조건 궤적을 사용했다. 초기화는 시드 0이며 검증 시드 24개는 고정·이동 궤적을 모두 검증에 사용했다. 테스트 시드 32개는 두 조건 모두 학습·검증에서 제외했다. 기존 고정 전용 체크포인트와 혼합 학습 체크포인트에 동일한 테스트 그래프를 제공했다.

## 결과

60개 고정 학습 궤적의 6,151프레임과 60개 이동 조건 학습 궤적의 6,421프레임을 섞었다. 후자 중 1,348프레임에서 Box가 실제 이동했다. 검증 데이터 5,295프레임에서 가장 낮은 손실인 0.031916을 기록한 40에폭 체크포인트를 선택했다.

테스트 32개는 모두 실제로 이동했고 expert가 삽입 단계에 진입했다. 이동 종료 변위는 60.7–119.9 mm, 중앙값 93.0 mm다. GT 점을 가진 동일 테스트 프레임에서 두 모델을 비교했다.

| 조건 | 프레임 | 횡방향 P90 고정 전용 → 혼합 (mm) | Hole 중심 P90 (mm) | Hole 삽입축 P90 (°) |
| --- | ---: | ---: | ---: | ---: |
| Box 이동 중 | 695 | 2.41 → 2.86 | 2.36 → 2.86 | 2.80 → 2.16 |
| Box 이동 후 | 580 | 2.06 → 2.69 | 2.28 → 2.81 | 2.83 → 1.85 |
| 이동 조건 삽입 직전 | 160 | 2.07 → 2.67 | 2.35 → 2.82 | 2.50 → 1.87 |
| 고정 조건 삽입 직전 | 160 | 2.10 → 2.67 | 2.35 → 2.82 | 2.50 → 1.87 |

횡방향 오차는 GT의 Peg 끝점–Hole 중심 상대 벡터와 모델 예측의 차이에서 GT 삽입축에 수직인 성분이다. 두 모델은 각 조건에서 동일한 테스트 시드와 프레임으로 비교했다.

이동 궤적을 포함한 학습은 이번 표본에서 Hole 삽입축 오차를 줄였고, 중심 및 끝점 횡방향 오차는 커졌다. 두 GNN은 현재 한 프레임의 GT 좌표만으로 추론한다. 고정 Box로 학습한 모델도 장면별 위치가 다른 GT 점으로 학습했으며 테스트에서 이동 중의 현재 GT 점을 받았다. 이 실험은 시간 추적이나 검출 오차를 평가하지 않는다. 학습 세트 구성과 검증 세트, 모델 가중치가 달라 혼합 비중별 인과 효과를 분리하지 않았다.

## 실행 검증

Vast.ai RTX 3090에서 CPU PhysX로 수집하고 CUDA로 학습했다. 40에폭 학습 및 테스트에는 369초가 걸렸다. 첫 데이터 생성은 NumPy 정수를 요약 JSON으로 기록하는 단계에서 종료됐다. 스칼라 변환을 수정한 뒤 재수집 전체가 성공했고, 완료된 수집 데이터만 사용했다. 시드 분할, 데이터와 학습 스크립트 해시, 기록한 이동량과 실제 GT 위치의 일치, 최저 검증 체크포인트를 확인했다. 저장된 두 모델 예측으로 이동 중 횡방향 P90을 NumPy에서 다시 계산했다.
