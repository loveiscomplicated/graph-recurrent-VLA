# 시뮬레이터 전체 GT 꼭짓점으로 동결 GNN 평가

## 질문과 설정

[가시 GT 직접 입력 평가](visible_gt_direct_gnn.md)에서 검출기와 추적기를 우회해도 오차가 남았다. 이번에는 카메라 가시성 조건을 제거하고 가려진 점까지 시뮬레이터 상태로부터 만들어 동일한 동결 GNN에 입력했다. 직접 주입한 값은 GT Object21 출력이 아니라, 물체 자세와 치수로부터 얻은 월드 좌표계 GT 3D 꼭짓점이다. GT Object21은 점수 계산에 사용했다.

| 조건 | Peg | Box 외곽 | Hole | 합계 |
| --- | --- | --- | --- | --- |
| 기존 가시 GT 직접 입력 | 가시 점만 | 가시 점만 | 가시 앞쪽 점만 | 프레임마다 다름 |
| 전체 GT, 앞쪽 Hole | 8개 | 8개 | 앞쪽 4개 | 20개 |
| 전체 GT, 양쪽 Hole | 8개 | 8개 | 앞쪽 4개와 뒤쪽 4개 | 24개 |

시뮬레이터 관측은 `state_dict`를 사용했고 RGB, Depth 및 가시성 마스크를 읽지 않았다. Peg 노드(0)와 Box 노드(1), TCP 좌표, 현재 관측 플래그를 사용하는 기존 그래프 입력 형식을 유지했다. Hole 점은 Box 노드 타입을 공유하고 별도 앞/뒤 또는 꼭짓점 ID는 없다. 전체 GT의 모든 입력 노드에 현재 관측 플래그를 설정했다. 검출기, 추적기, 필터, Recurrent를 실행하지 않았다. 두 GT 조건에서 GNN 가중치와 비교 대상 GT 21D는 같다.

기존 초기 시드 200–1399와 scripted expert 16개를 같은 방식으로 준비했다. 기존 평가와 동일한 마지막 다섯 파지 유지·정렬 스텝을 삽입 직전으로 집계했다. 로봇의 행동은 이전 실험과 같이 동일 scripted expert로 재생성했으며 GNN의 예측을 행동에 사용하지 않았다.

## 결과

이전 가시 GT 평가와 동일한 1,839프레임을 확인했다. seed, step, 조작 단계, expert 종료 상태, GT 21D가 모두 일치했다. 삽입 직전은 15개 시드의 75프레임이다. 아래 각 셀은 중앙값 / P90이다.

| 구간 | 입력 | Peg 중심 (mm) | Peg 축 (°) | Hole 중심 (mm) | Hole 축 (°) | 횡방향 (mm) |

| 초기 (1200) | 전체 20점 | 4.45 / 6.22 | 0.54 / 1.40 | 9.13 / 15.84 | 4.02 / 6.20 | 9.77 / 17.87 |
| 초기 (1200) | 전체 24점 | 5.04 / 6.15 | 0.59 / 1.57 | 17.99 / 28.69 | 21.31 / 30.60 | 17.74 / 29.19 |
| 첫 파지 (15) | 가시 GT | 80.72 / 153.60 | 12.40 / 66.30 | 13.56 / 25.88 | 1.04 / 3.06 | 13.00 / 137.12 |
| 첫 파지 (15) | 전체 20점 | 5.22 / 6.09 | 0.41 / 1.64 | 10.14 / 13.72 | 4.82 / 5.63 | 10.99 / 14.87 |

| 파지 유지·정렬 (624) | 전체 24점 | 4.02 / 7.27 | 0.54 / 1.17 | 19.14 / 24.87 | 18.60 / 29.91 | 17.95 / 23.78 |

- 가려져 있던 앞쪽 GT 점까지 준 20점 조건에서 첫 파지의 Peg 중심 P90은 153.60 → 6.09 mm, 삽입 직전 횡방향 P90은 31.70 → 13.68 mm로 줄었다. 현재 가시점만 제공하는 조건에서 부족한 입력점이 특히 조작 단계의 큰 오차에 영향을 줬다.
- 20점 조건에서도 삽입 직전 Hole 중심 P90 14.15 mm와 횡방향 P90 13.68 mm가 남았다. 기하 끝점은 횡방향 P90 13.88 mm이고 보정 후에는 13.68 mm였다. 정확한 GT 점을 받은 상태에서도 동결 모델의 물체 상태 추정에 오차가 남았다.
- 뒤쪽 Hole 네 점만 추가한 24점 입력에서 삽입 직전 Hole 축 P90이 5.59° → 29.99°로 늘었다. 입력에는 Box 외곽과 Hole 림, Hole 앞쪽과 뒤쪽을 나누는 의미 ID가 없다. 추가된 점을 현재 체크포인트가 어떻게 해석하는지에 민감하다는 결과다. 학습 분포 차이와 네트워크 설계의 기여는 이 실험만으로 분리할 수 없다.
- 초기 프레임에서는 가시 GT의 횡방향 P90이 14.90 mm였고 전체 20점에서는 17.87 mm였다. 20점 제공의 효과는 조작 단계에 따라 달랐다.

## 검증 및 산출물

Vast.ai RTX 3090에서 PyTorch 2.14.1+cu132, ManiSkill 3.0.1, CPU PhysX 및 CUDA GNN 추론으로 실행했다. 네 실행의 완료 상태와 GNN 체크포인트 해시, 가시 GT 실험과의 프레임 정렬 및 GT 동일성을 확인했다. 각 조건에서 점 수와 모든 Object21 출력의 유한값, 기하 끝점과 잔차의 합을 검사했다. 저장소 모델과 환경 코드는 편집하지 않았다.
