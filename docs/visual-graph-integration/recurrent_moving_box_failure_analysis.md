# 이동 Box에서 재학습 Mamba의 삽입 실패 분석

[새 앞단 Mamba 재학습 실험](recurrent_new_frontend.md)의 이동 Box 32개 시드를 기존 Mamba와 재학습 Mamba에서 일대일로 비교했다. 두 조건의 앞단, Box 이동 계획, 카메라 및 필터 우회 설정이 같다. 매 프레임 Mamba가 입력받은 Object21, GT Object21, Peg 파지 여부 및 Box 이동 이력을 분석했다. 두 정책의 경로가 달라진 이후에는 관측도 달라진다.

## 측정 방법

설치된 ManiSkill의 `PegInsertionSide-v1`은 Hole 기준 삽입축을 x로 두고, Box 입구 면은 `x = −Box 반길이`에 있다. Box 반길이는 Peg 반길이와 같다. 따라서 입구 기준 깊이는 Hole 좌표계의 GT Peg 끝점 x에 GT Peg 반길이를 더해서 계산했다. 0 mm는 입구 면, 양수는 입구 면을 지난 위치다. 성공 판정은 Peg 끝점 x가 −15 mm 이상이고 y, z가 각각 Hole 반폭 안에 들어오는 조건이다. 로그가 행동 직전의 상태를 저장하므로 성공 롤아웃의 마지막 기록은 성공 판정을 만든 행동 직전이다.

실제 횡방향 이탈은 GT Peg 끝점과 Hole 축 사이의 거리다. Object21의 횡방향 추정 오차는 예측된 Peg 끝점과 Hole 사이 벡터를 GT와 비교해 y, z 성분의 오차 크기를 계산했다. Hole 중심 추정 오차는 좌표 3성분을 GT와 비교했다. 표의 P90은 각 장면 안에서 계산하고 장면별 P90의 중앙값을 보고했다. 실패 분류에서 마지막 20스텝의 깊이 중앙값이 입구 면 ±10 mm 이내인지를 사용했다. 이 ±10 mm는 로그 분석을 위한 기준이다.

## 결과

| 이동 Box 지표 | 기존 Mamba | 재학습 Mamba |
| --- | ---: | ---: |
| 삽입 성공 | 14/32 | 11/32 |
| 마지막까지 파지하고 시간 초과 | 18/18 실패 | 21/21 실패 |
| 마지막 20스텝에서 입구 면 ±10 mm에 머문 실패 | 13/18 | 17/21 |
| 실패 장면의 이동 중 Hole 중심 오차 P90 중앙값 | 2.38 mm | 2.36 mm |
| 실패 장면의 이동 종료 후 Hole 중심 오차 P90 중앙값 | 3.54 mm | 3.25 mm |

재학습 모델로 입구 면에 머문 17회에서 마지막 20스텝의 깊이 변화 범위는 장면별 중앙값 **0.15 mm**였다. 같은 구간의 실제 Peg 횡방향 이탈은 장면별 중앙값 **14.6 mm**(5.6~21.3 mm)였다. 나머지 4회 중 2회는 마지막에 입구 면에 못 미쳤고, 2회는 입구 면을 지나 접근했지만 성공 깊이에 도달하지 못했다. 이동에서 실패한 21개 시드 중 17개는 같은 재학습 Mamba가 고정 조건에서 성공했다.

기존 Mamba는 성공하고 재학습 Mamba만 실패한 6개 시드(`700674`, `700729`, `700732`, `700839`, `700855`, `700911`) 모두 이 입구 면 정체에 해당했다. 이 6회에서 Box가 움직이는 동안 Hole 추정 P90은 **1.27~2.56 mm**였다. 반대로 재학습 모델만 성공한 시드는 `700563`, `700578`, `701109` 세 개였다.

| 시드 | 기존 → 재학습 | 재학습 모델에서 관찰한 구간 |
| --- | --- | --- |
| 700674 | 성공 → 실패 | 실제 Peg 끝점이 옆으로 **18.6 mm** 벗어났고 입구 면에 머물렀다. 마지막 프레임의 Object21 횡방향 추정 오차는 **1.1 mm**였다. 이동 이후 전체 구간의 추정 오차 P90은 **4.36 mm**였다. |
| 700732 | 성공 → 실패 | 실제 Peg 끝점이 옆으로 **5.6 mm** 벗어난 상태에서 입구 면 부근에 머물렀다. 이동 종료 후 Hole 중심 추정 오차 P90은 **2.22 mm**였다. |
| 700882 | 실패 → 실패 | 실제 Peg 끝점은 마지막에 옆으로 **3.0 mm** 벗어나고 성공 깊이에 약 **6.2 mm** 못 미쳤다. 같은 프레임의 Object21 횡방향 추정 오차는 **61.3 mm**였고 Hole 중심 오차는 약 **2.0 mm**였다. |

## 해석

이동 후 가장 자주 보인 실패는 Peg를 든 채 입구 면에서 횡방향 오차를 줄이지 못하고 정체되는 패턴이다. 시드 700674는 마지막 시점에 Graph 입력이 실제 이탈을 반영했어도 로봇이 정렬을 복구하지 못한 사례다. 반면 시드 700882처럼 구멍 중심이 잘 추정된 상황에서도 Peg와 Hole의 상대 위치가 크게 틀어지는 사례가 있다. 가중치를 바꾸면 로봇 경로와 가시성도 바뀌므로, 동일 시드 비교만으로 추정 오차와 Mamba의 제어 반응이 각각 얼마나 실패에 기여했는지 확정할 수 없다. 로그에 외력·접촉 정보가 없어 입구 면과의 충돌 여부는 확인하지 않았다.

두 영향을 분리하려면 같은 이동 종료 상태와 Mamba 이력에서 재생하고, 몇 개 대표 시드에서 Object21만 GT로 바꿔 진입 여부를 비교한다. 계속 실패하는 시드에서는 실제 위치를 받은 정책이 횡방향 보정과 삽입축 진행을 어떻게 선택하는지 확인한다. 이번 작업은 저장된 CUDA 롤아웃의 로컬 분석이며 시뮬레이션은 재실행하지 않았다.

## 기존 GNN 단독 평가와 비교

[GNN 단독 평가](hybrid_input_gnn_finetune.md)의 테스트 예측과 폐루프 기록을 같은 횡방향 오차로 다시 비교했다. 단독 평가의 `best.pt` SHA-256이 기존 및 재학습 Mamba의 모든 폐루프 평가 설정에 기록된 GNN SHA-256과 일치했다. 아래는 프레임을 합쳐 계산한 P90으로, 앞 표의 장면별 P90 중앙값과 집계 방식이 다르다.

| 평가 구간 | 프레임 수 | 횡방향 오차 P90 | 최대 횡방향 오차 |
| --- | ---: | ---: | ---: |
| GNN 단독, Expert 궤적 전체 | 3,352 | 3.47 mm | 18.65 mm |
| GNN 단독, Box 이동 중 | 695 | 3.64 mm | 18.65 mm |
| GNN 단독, 삽입 직전 5프레임씩 | 160 | 3.52 mm | 4.66 mm |
| 재학습 Mamba 폐루프, Box 이동 중 | 686 | 4.27 mm | 47.89 mm |
| 재학습 Mamba 폐루프, Box 이동 종료 후 | 3,896 | 16.48 mm | 66.29 mm |

GNN 단독 평가에서는 Expert가 정렬하다 삽입을 시작하면 수집을 끝냈다. 폐루프에서는 Mamba가 만든 경로에서 삽입 진입, 실패 정체, 복구 구간까지 관측했다. 두 평가의 환경 시드도 다르다. 재학습 폐루프에서 60 mm 이상인 43프레임은 전부 시드 `700882`의 이동 종료 후 구간에서 기록됐다. 그 장면의 마지막 프레임에서 Peg 끝점 3D 추정 오차는 72.36 mm, Hole 중심 오차는 1.97 mm였다. 이 비교로 큰 오차가 기록된 구간과 성분은 확인했지만, 해당 프레임에서 검출·추적·GNN의 개별 기여는 분리하지 않았다.
