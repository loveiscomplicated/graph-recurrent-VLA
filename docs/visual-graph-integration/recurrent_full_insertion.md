# 전체 삽입 구간으로 재학습한 앞단에 Mamba 연결

[삽입 끝까지 학습한 Transformer와 GNN](full_insertion_frontend.md)을 고정하고, [이전 Mamba 파인튜닝](recurrent_new_frontend.md)의 데이터와 학습 설정을 유지했다. 실측 꼭짓점은 RANSAC 검출 그대로 통과하고 현재 검출되지 않은 슬롯만 Transformer가 채운다. 기존 Box 강체 보정과 GT 기반 꼭짓점 ID 대응을 유지한다.

## 데이터와 학습

Expert 데이터의 학습 116개와 검증 21개, 16,693개의 행동 프레임을 동일하게 사용했다. 전체 삽입 검출 자료를 동일 시드·스텝·Expert 단계에 맞춰 재생하고 새 Transformer와 GNN에서 Object21을 다시 계산했다. 기존 Robot15, GT Object21과 Expert Action7은 보존했다. 두 원본 수집의 상태가 수치상 완전히 같지는 않으므로 시드별 프레임 수와 단계가 완전히 일치하고, 각 프레임의 GT 위치 벡터 차이가 0.05 mm 이하, 회전 차이가 0.05° 이하일 때만 결합했다. 최종 성공 직후 관측에는 Expert 행동이 없어 BC 학습 대상에서 제외했다.

두 앞단 비교에서 Mamba 5개는 모두 같은 Recurrent 팀 원본 체크포인트로 초기화했다. 기존 Behavior Cloning을 그대로 사용했다. 입력용 Object21은 GT와 해당 앞단의 예측을 에피소드별 혼합 계수 0·0.25·0.5·0.75·1로 섞었고, 로봇 상태 및 Expert Action7은 같다. 배치에 고정 데모 4개, 이동 데모 4개를 넣었다. 각 모델은 최대 1,000회 업데이트했으며, 추론과 같은 Graph 100% 입력에서 고정·이동 검증 행동 손실의 평균이 가장 작았던 가중치를 골랐다. Recurrent 누적 평균 필터는 끈 상태를 유지했다.

## 폐루프 비교

이전 실험과 동일한 32개 시드를 고정 Box와 이동 Box 각각 실행했다. 두 앞단이 모두 GT를 사용하는 곳은 검출 후보의 꼭짓점 번호 배정이다. 실행 시 Mamba의 Object21은 각 조건의 GNN이 예측했다. 이동은 같은 시드의 60스텝 시작 계획과 경로 가드를 사용하므로, 조건에 따라 가드에 걸리는 시점과 최종 이동량은 달라질 수 있다. 이 비교에서는 앞단과 Mamba 가중치가 함께 바뀌었다.

| Mamba 시드 | 초기 손실 | 최저 손실 | 선택한 업데이트 |

다섯 실행 모두 처음 정한 1,000 업데이트 한도에서 종료했다. 손실 표의 초기와 최저는 모두 새 GNN의 Object21을 입력한 같은 검증 데모에서 계산했다.

## 폐루프 결과

| Box 조건 | 이전 앞단 + 이전 파인튜닝 Mamba | 전체 삽입 앞단 + 새 Mamba | 양쪽 성공 | 이전만 성공 | 새 조합만 성공 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 고정 | 24/32 (75.0%) | 21/32 (65.6%) | 17 | 7 | 4 |
| 이동 | 11/32 (34.4%) | 14/32 (43.8%) | 10 | 1 | 4 |

이동 조건은 새 조합의 32개 모두 Box가 실제로 움직였다. 두 조건의 전체 성공은 각각 35/64로 같다. 고정에서는 순성공 3건을 잃었고 이동에서는 순성공 3건을 얻었다. 관찰한 두 대표 시드 700674와 700882는 두 앞단에서 모두 고정 성공·이동 실패였다. 700674의 이동 변위는 114.67 mm로 같았고, 700882는 같은 이동 계획에서 가드가 발동하는 시점이 달라 이전 81.76 mm에서 새 98.11 mm로 달라졌다.

## 검증 및 산출물

RTX 3090에서 실행했다. 기존 수집의 로봇 상태·정답·행동, 앞단 모델 2개, Mamba 5개, 초기 GT, 카메라, 이동 계획, 필터 우회 및 성공 집계를 확인했다. Expert 데이터 결합 시 최대 위치 차이는 0.041 mm, 최대 회전 차이는 0.038°였다. 파인튜닝 조건을 유지했으므로 이번 결과는 새 앞단에 맞춰 학습한 조합을 비교하며, GT 혼합 여부나 앞단과 Mamba의 개별 효과는 여기서 분리하지 않는다.
