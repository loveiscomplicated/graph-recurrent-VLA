# Graph–Recurrent VLA 최종 파이프라인

## 전체 파이프라인 소개

목표는 ManiSkill3의 `PegInsertionSide-v1`에서 RGB-D로 Peg와 Hole의 3D 상태를 추정하고, 그 상태를 받은 Recurrent 정책으로 Peg를 삽입하는 것이다. 고정 Box와 평행이동하는 Box를 평가했다.

```text
메인 카메라 RGB-D + 카메라 보정값
        ↓
1. 검출기 + 꼭짓점 번호 배정
   Peg 8점 · Box 외곽 8점 · Hole 입구 4점의 관측 슬롯
        ↓
2. 공간·시간 Transformer 추적기
   미검출 슬롯의 현재 3D 좌표 복원
        ↓
3. Box·Hole 강체 보정기
   같은 강체의 공통 이동으로 누락된 Box·Hole 좌표 보정
        ↓
4. GNN
   20점과 TCP, 검출 여부 → Object21
        ↓
5. Mamba
   Object21 + 로봇 상태 → Action7
        ↓
로봇과 환경이 움직임 → 다음 카메라 관측
```

카메라 영상으로부터 Object21까지를 앞단으로 확정했다. 앞단의 Transformer와 GNN은 각각 좌표와 물체 상태를 정답으로 학습했고, Mamba는 Expert Action을 정답으로 학습했다.

앞단 단독 평가는 Expert가 움직인 별도 테스트 궤적 24개, 2,873프레임에서 진행했다. 이후 폐루프 평가는 Mamba의 행동으로 다음 관측이 결정되는 방식으로 고정·이동 각각 32개 시드를 실행했다. 아래 P90은 오차의 90번째 백분위수이며, 각 표에 평가 범위를 표시했다.

## 1. 검출기와 꼭짓점 번호 배정

### 역할과 입력·출력

RGB-D에서 보이는 물체의 꼭짓점 후보를 월드 좌표계의 3D 좌표로 만들고, 어떤 물리 꼭짓점인지 고정된 슬롯에 배정한다.

- 입력은 메인 카메라의 RGB와 Depth, 카메라 내부·외부 파라미터, 번호 배정에 사용하는 로봇 TCP 위치다.
- 출력 슬롯은 Peg 8개, Box 외곽 8개, 앞쪽 Hole 입구 4개로 총 20개다.
- 각 슬롯에는 이번 프레임에서 좌표가 검출·배정됐는지를 나타내는 마스크가 붙는다.

### 작동 방식과 학습 여부

이 단계는 기하와 규칙 기반으로 동작한다. 이번 실험에서는 검출기를 고정하고 Transformer와 GNN을 학습했다.

1. RGB의 물체·색상·경계 후보와 Depth의 3D 기하를 사용해 면과 모서리 후보를 구성한다.
2. CUDA에서 `plane_fit_method='ransac'`을 명시해 평면을 추정한다. 면과 경계 정보에서 Peg, Box 외곽, Hole 입구의 꼭짓점 후보를 찾는다.
3. 카메라 보정값으로 후보 좌표를 월드 좌표로 변환한다.
4. 물체별 형태와 이전 프레임의 자세를 사용해 후보를 20개 물리 슬롯에 일대일 배정한다.

Peg는 처음 테이블에 놓인 자세와 길이·폭을 초기화하고, 이후 직전 자세와 후보를 대응시킨다. 비공선 대응점이 세 개 이상이면 강체 회전을 갱신한다. Box 외곽은 큐브 형태와 작업공간 방향 범위를 사용한다. Hole 입구는 같은 Box 좌표계의 사각형으로 초기화한 뒤 Box의 이동에 따라 예상 위치를 갱신한다.

배정이 끝난 슬롯에는 검출기의 좌표를 그대로 넣는다. 배정되지 않은 슬롯은 추적기로 넘긴다. 번호 추론에는 물체 GT와 시뮬레이터 segmentation을 사용하지 않는다. GT는 배정 후 정확도를 채점하는 데 사용한다.

### 결과

최종 앞단 테스트 24개, 2,873프레임에서 번호가 배정된 검출 좌표를 같은 물리 슬롯의 GT와 비교했다.

| 대상 | 배정된 검출점의 3D 오차 P90 | 해당 번호 GT의 5 mm 이내 / 전체 배정 |
| --- | ---: | ---: |
| Peg | 1.45 mm | 15,509 / 15,622 |
| Box 외곽 | 1.87 mm | 16,384 / 16,390 |
| Hole 입구 | 3.22 mm | 9,570 / 9,729 |
| 전체 | 2.49 mm | 41,463 / 41,741 |

이 표의 분모는 검출 좌표가 배정된 슬롯이다. 미검출 슬롯은 다음 추적기 표에 포함된다. 따라서 이 값으로 전체 가시점 재현율이나 모든 프레임의 번호 정확도를 대신할 수는 없다. 현재 번호 규칙의 검증 범위는 초기 자세 범위와 Box 평행이동 조건이다.

## 2. 공간·시간 Transformer 추적기

### 역할과 입력·출력

현재 검출되지 않은 꼭짓점의 현재 3D 좌표를 추정한다. 화면에서 오래 가려진 점도 20개 슬롯 안에 유지해 다음 보정기와 GNN이 사용할 좌표를 채운다.

점마다 다음 정보를 사용한다.

- 고정 슬롯 ID와 슬롯별 학습 가능한 ID embedding
- 해당 점의 마지막 검출 좌표
- TCP와 마지막 검출 좌표 사이 상대 위치
- 현재 검출 여부와 과거 관측 여부
- 마지막 검출 이후 경과 시간과 에피소드 내 시간

아직 한 번도 검출되지 않은 슬롯은 학습 세트에서 구한 슬롯별 평균 좌표를 기준점으로 사용한다.

### 모델의 작동 방식

모델은 폭 48, attention head 4개의 구조를 사용한다. 연산 순서는 다음과 같다.

```text
슬롯별 입력 특징 + ID embedding + 시간 위치 정보
        ↓
첫 번째 causal 시간 attention
        ↓
같은 강체 안의 공간 attention
        ↓
두 번째 causal 시간 attention
        ↓
기준 좌표에 대한 3D 보정량 예측
```

시간 attention은 같은 점의 현재와 과거 관측을 읽는다. 공간 attention에서는 Peg 8점을 하나의 강체 그룹으로, Box 외곽 8점과 Hole 입구 4점을 같은 강체 그룹으로 묶는다. 현재 보이는 다른 점으로부터 미검출점의 움직임을 추론하도록 학습한다.

이번 프레임에 직접 검출된 슬롯은 검출 좌표가 최종 출력에 그대로 남는다. 모델 예측은 미검출 슬롯에 적용된다. 실행 중에는 시간 attention의 이전 상태를 이어 사용하고 새 에피소드에서 초기화한다.

### 학습 방식

고정·이동 Box의 성공 Expert 궤적 116개를 학습에, 21개를 검증에 사용했다. 입력 좌표와 검출 마스크는 최종 검출기와 GT 없는 번호 배정으로 만든다. 정답은 같은 시점의 시뮬레이터 GT 3D 꼭짓점이다.

손실은 현재 미검출인 슬롯의 예측 좌표와 GT 사이 Smooth L1이다. 실제 검출된 좌표를 정답으로 덮어 입력하는 과정은 없다. 검증에서는 삽입 전과 삽입 후의 미검출점 평균 3D 오차를 같은 비중으로 합산해 체크포인트를 선택했다.

기존 전체 삽입 학습 가중치에서 파인튜닝해 추가 342에폭에서 최저 학습률 정체 조건을 충족했다. 추가 333에폭의 최저 검증 가중치를 최종 선택했다.

## 3. Box·Hole 강체 보정기

### 역할과 입력·출력

Box 외곽과 Hole 입구가 같은 강체라는 관계를 사용해, 현재 관측되지 않은 Box·Hole 점의 좌표를 보정한다. 입력은 Transformer가 채운 20점, 현재 검출 마스크, Box 외곽 슬롯 정보다.

### 작동 방식과 학습 여부

추가 학습이 없는 규칙 기반 보정기다. Box 방향이 고정된 평행이동을 가정한다.

1. 처음 관측된 Box·Hole 점의 기준 위치를 등록한다.
2. 이전에 등록된 Box 외곽점 중 현재 다시 검출된 점을 찾는다.
3. 각 외곽점의 기준 위치 대비 이동량을 구한다.
4. 최소 세 점의 이동량이 8 mm 이내에서 합의하면 공통 이동량을 갱신한다. 프레임당 최대 이동 속도 조건도 확인한다.
5. 등록됐지만 현재 미검출인 Box·Hole 슬롯을 기준 좌표 + 공통 이동량으로 보정한다.
6. 관측이 잠시 끊기면 추정 속도를 최대 5프레임까지 외삽한다.

직접 검출된 좌표는 보존한다. Peg와 아직 한 번도 관측되지 않은 슬롯은 Transformer의 좌표를 유지한다.

### 결과

최종 테스트의 같은 미검출 슬롯에서 보정 전후를 비교했다.

| 대상 | 전체 미검출점 3D 오차 P90, 보정 전 → 후 |
| --- | ---: |
| Peg | 10.17 → 10.17 mm |
| Box 외곽 | 5.39 → 3.82 mm |
| Hole 입구 | 5.98 → 3.35 mm |
| 전체 | 7.73 → 6.99 mm |

| 깊은 삽입 중 미검출점 | 보정 전 → 후 3D 오차 P90 |
| --- | ---: |
| Box 외곽 | 12.51 → 5.49 mm |
| Hole 입구 | 6.60 → 3.35 mm |

보정기는 Box·Hole의 동일 이동을 이용한다. Peg의 가림 이후 좌표 오차는 이 보정기를 거쳐도 유지된다.

## 4. Object21 GNN

### 역할과 입력·출력

검출·추적·보정을 거친 점 집합에서 로봇 제어에 사용할 물체 상태를 추정한다. 입력은 20개 3D 좌표, 각 점의 현재 직접 검출 여부, TCP 위치다.

20개 점을 그래프 노드로 두고 자기 자신을 제외한 모든 노드를 연결한다. 간선에는 상대 좌표와 거리, 같은 물체 그룹인지에 대한 정보를 사용한다. Edge-gated message passing으로 점 사이 정보를 모은 뒤 Object21을 출력한다.

| Object21 구성 | 차원 | 의미 |
| --- | ---: | --- |
| Peg 중심 | 3 | TCP 기준 Peg 중심 위치 |
| Peg 자세 | 4 | Peg quaternion |
| Peg 끝점 상대 위치 | 3 | Hole 중심에서 Peg 끝점으로 향하는 벡터 |
| Hole 중심 | 3 | TCP 기준 Hole 중심 위치 |
| Hole 자세 | 4 | Hole quaternion |
| Peg 형상 | 3 | 세 축의 반치수 |
| Hole 크기 | 1 | Hole 반경 |
| 합계 | 21 | Recurrent에 전달하는 물체 상태 |

상대 위치 벡터는 월드 축으로 표현한다. 제어 특징을 만들 때 Hole 좌표계로 추가 변환한다.

### 학습 방식

Transformer의 최저 검증 가중치를 동결하고, 그 출력에 강체 보정을 적용해 GNN의 입력 좌표를 생성했다. 정답은 같은 프레임의 시뮬레이터 GT Object21이다. 기존 Object21 위치·자세·형상 손실과 학습 루프를 재사용했다.

학습 116개와 검증 21개의 Expert 궤적을 사용했다. 입력 좌표에는 검출기·추적기·보정기의 오차가 포함된다. GNN은 그 입력에서 정확한 물체 상태를 예측하도록 학습했다.

기존 전체 삽입 GNN에서 파인튜닝해 추가 38에폭에서 최저 학습률 정체 조건을 충족했다. 검증 손실이 가장 낮았던 추가 2에폭 가중치를 선택했다.

### 결과

동일한 최종 Transformer와 강체 보정 좌표를 두 GNN에 넣어 비교했다. 횡방향 오차는 GT Hole 축에 수직인 평면에서 Peg 끝점 상대 벡터의 예측과 GT 사이 거리다.

## 5. Mamba Recurrent 모듈과 최종 제어 결과

### 역할과 입력·출력

Mamba는 앞단이 추정한 물체 상태와 로봇 상태의 시간 흐름을 받아 이번 스텝의 행동을 예측한다. 기존 Recurrent 팀 Mamba 모델 5개를 앙상블로 사용한다.

Robot15에는 TCP 위치·자세, TCP 기준 양쪽 손끝 위치, 두 그리퍼 관절 위치가 포함된다. Robot15와 Object21을 합치면 36차원이다. TCP 회전을 quaternion 4차원에서 6D로 바꾸고, Hole 좌표계의 Peg 끝점 위치 3개와 상대 회전 3개를 추가해 최종 44차원 특징을 만든다. 체크포인트의 정규화 통계를 적용하고 시간 상태를 유지하며 Action7을 출력한다.

Action7은 이동 3개, 회전 3개, 그리퍼 1개다. `pd_ee_delta_pose` 컨트롤러가 이 행동을 실행하면 로봇이 움직이고 다음 카메라 관측이 결정된다. 새 에피소드에서는 Recurrent 상태를 초기화한다.

앞단의 Box·Hole 보정은 계속 사용한다. Recurrent 입력 단계의 과거 위치 누적 평균 필터는 꺼두고 GNN Object21을 특징 변환에 전달한다.

### 학습 방식

기존 Mamba 앙상블을 최종 앞단에 바로 붙인 조건과, 해당 Mamba를 추가 학습한 조건을 비교했다.

파인튜닝 데이터는 성공 Expert 궤적 137개, 행동 시점 16,693프레임이다. 116개는 학습에, 21개는 검증과 체크포인트 선택에 사용했다. 최종 앞단으로 Expert 궤적을 처리해 Object21 시퀀스를 다시 생성하고 같은 시점의 Robot15와 Expert Action7을 맞췄다.

파인튜닝 입력에는 앞단이 추정한 Object21만 사용했다. 정답은 그 프레임의 Expert Action7이다. 기존 원본 Mamba의 학습 계보에는 GT·Graph 혼합 학습이 포함돼 있다.

각 모델은 기존 가중치에서 시작했고 배치에는 고정·이동 궤적을 각각 4개씩 넣었다. 고정·이동 검증 행동 손실을 같은 비중으로 평균해 가중치를 선택했다. 다섯 모델 모두 최저 학습률에서 정체 조건을 충족했다. 학습은 저장된 Expert 관측과 행동을 이용하는 BC이며, 행동 실행 결과의 성공 판정은 별도의 폐루프 평가에서 측정했다.

### 최종 성공률

같은 시드 32개를 고정 Box와 이동 Box에서 각각 실행했다. 두 조건 모두 최종 앞단을 고정하고 최대 250스텝, 같은 카메라와 이동 계획으로 비교했다. 이동 조건의 Box는 두 정책에서 32개 모두 실제로 움직였다.

| 조건 | 기존 Mamba 그대로 연결 | 최종 앞단 출력으로 파인튜닝 |
| --- | ---: | ---: |
| 고정 Box | 62.5% (20/32) | 62.5% (20/32) |
| 이동 Box | 43.75% (14/32) | 31.25% (10/32) |

검증 행동 손실은 다섯 모델 평균 0.02748 → 0.02409로 약 12% 줄었다. 같은 시드의 이동 성공률은 12.5%p 낮아졌다.

## 6. 현재 남은 문제와 해결해야 할 항목

### 얕은 진입 이후 장시간 Peg 무검출

Expert 테스트의 얕은 진입 94프레임에는 Peg 8개 슬롯이 전부 빈 경우가 없었다. 전체 2,873프레임에서도 4프레임이었고 각각 한 프레임씩이었다.

이동 시드 700882의 파인튜닝 후 폐루프에서는 66스텝부터 종료까지 Peg 직접 검출 슬롯이 184프레임 연속 비었다. 횡방향 오차는 79스텝부터 50 mm를 넘었다. 해당 시드의 얕은 진입에서 50 mm 이상인 프레임은 85개였으며, 이동 조건의 큰 얕은 진입 오차가 이 시드에 집중됐다.

원본 RGB-D 기록이 없어 같은 시드에서 저장 행동과 Box 이동 계획을 재생했다. Mamba를 실행하지 않고 관측을 다시 앞단에 넣어도 85프레임 모두 같은 큰 오차가 재현됐다. 이 조건은 앞단 단독 Expert 테스트에서 충분히 다뤄지지 않았다.

### 후속 검증 항목

1. 같은 실패 프레임에서 원시 검출 후보, 번호 배정 결과, Transformer 좌표, 보정 좌표, Object21을 함께 저장해 오차가 커지는 단계를 확인한다. 실제 가림으로 후보가 사라졌는지, 번호 배정에서 후보가 탈락했는지도 구분한다.
2. 현재 앞단에 장시간 Peg 무검출을 포함한 테스트를 추가하고, 파지 후 TCP 변화와 손–Peg 상대 자세를 이용하는 복원 후보를 비교한다. 접촉 중 미끄러짐과 파지 이탈은 별도로 검증한다.
3. Recurrent 팀은 같은 최종 앞단과 평가 시드에서 얕은 진입 후 정체·후퇴하는 동작을 개선하고 성공률 변화를 확인한다.
4. Box 회전, 더 넓은 초기 자세 범위, 실제 카메라·로봇은 후속 평가 범위로 남아 있다.
