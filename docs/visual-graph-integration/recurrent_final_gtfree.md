# 최종 GT 없는 앞단에 맞춘 기존 Mamba 파인튜닝

## 비교 조건

[최종 GT 없는 앞단](gtfree_frontend_retrain.md)의 RANSAC 검출기, 꼭짓점 번호 배정, Transformer, 강체 보정과 GNN을 양쪽에서 동결했다. 번호 배정에는 RGB-D 검출 후보와 TCP를 사용했다. 검출 좌표를 유지하고 Transformer가 미검출 슬롯을 채우며, 보정된 3D 좌표에서 GNN이 Object21을 출력한다.

시작점은 [이전 전체 삽입 실험에서 학습한 Mamba 다섯 개의 앙상블](recurrent_full_insertion.md)이다. 교체 전과 파인튜닝 후에 같은 앙상블 구성과 로봇 상태 입력, 정규화, 액션 디코딩을 사용했다. 파인튜닝은 앙상블의 각 모델을 해당 기존 체크포인트에서 시작했다. 모델 구조와 필터 우회는 [GT 없는 이전 폐루프 평가](recurrent_gtfree_ids.md)의 설정을 따랐다.

같은 Expert 궤적을 최종 앞단으로 전처리해 Robot State와 Object21을 구성했다. Expert 관측과 같은 프레임의 TCP·물체 pose·시점·행동을 기존 데모와 대조했다. 검증된 프레임 정렬 뒤 행동 정답을 그대로 사용하고, Object21은 최종 앞단의 예측만 사용했다. 평가 전의 첫 두 데모에서는 배치 처리와 온라인 처리의 Object21이 허용 오차 내에서 같은지 확인했다. 학습 116개와 검증 21개를 기존과 동일하게 분리했다. 체크포인트는 고정·이동 검증 행동 손실을 같은 비중으로 평균한 값으로 선택했다.

폐루프 성공률은 기존 32개 시드를 고정·이동 Box에서 각각 실행해 비교했다. 최대 250스텝과 Box 이동 계획, 카메라는 두 정책에 동일하게 적용했다. 이동이 시작되기 전 정책이 종료된 경우도 시드 단위 성공률에서 유지한다. 삽입에 들어간 뒤 실패했는지는 GT Peg 끝점 중심이 구멍 단면 안에 있으면서 입구를 0.1 mm보다 깊게 지난 프레임이 해당 궤적에 있었는지로 판단했다. 이 GT는 채점에 사용했다.

## 결과

Vast.ai RTX 3090에서 Expert 데이터 137개(16,693프레임)를 전처리하고 Mamba 5개를 파인튜닝했다. 학습 시 고정·이동 Box에서 각 4개씩 배치에 사용했다. 5개 모두 최저 학습률에서 검증 정체 조건을 충족해 종료했다. 선택 업데이트는 250, 450, 400, 250, 350이다. 고정·이동을 같은 비중으로 계산한 검증 행동 손실의 5개 모델 평균은 0.02748 → 0.02409로 줄었다.

| Box | 기존 Mamba | 파인튜닝 Mamba | 성공으로 바뀐 시드 | 실패로 바뀐 시드 | 구멍 진입 후 실패 기존 → 파인튜닝 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 고정 | 20/32 (62.5%) | 20/32 (62.5%) | 3 | 3 | 10 → 9 |
| 이동 | 14/32 (43.8%) | 10/32 (31.3%) | 1 | 5 | 13 → 16 |

이동 조건의 Box는 두 정책에서 32개 모두 실제로 움직였다. 이동에서 700878은 성공으로 바뀌었고, 700627, 700687, 700729, 700882, 701109는 실패로 바뀌었다. 이동의 삽입 후 실패 중 3 mm 이내 얕은 진입은 8 → 10건, 20 mm를 넘겨 들어간 뒤 정체된 경우는 2 → 4건이었다. 같은 시드 32쌍의 이동 성공 판정을 비교한 정확 검정의 양측 p값은 0.219다. 이번 비교에서는 Expert 궤적의 행동 손실 개선이 폐루프 성공률 개선으로 이어지지 않았다.

공통 ExperimentLogger 기록, 학습 데모 해시와 Mamba 체크포인트 해시, 검증 손실로 선택한 업데이트, 평가 시드·첫 관측·카메라·Box 이동 계획, 필터 우회 및 최대 250스텝 조건을 독립 검증했다. 원시 궤적과 파인튜닝 가중치는 아래 로컬 경로에 보관했다.

## 폐루프 Object21 횡방향 오차

GT Hole 축에 수직인 평면에서 GNN이 추정한 Peg 끝점의 상대 위치와 GT 사이의 거리를 측정했다. 두 정책은 같은 앞단을 쓰지만 각자 행동으로 만든 서로 다른 프레임을 관측했다. 아래 수치는 각 정책의 롤아웃에서 프레임을 모아 집계했다. 삽입 전은 Peg 끝점 중심이 입구 면을 통과하기 전이며, 얕은 진입과 깊은 삽입은 끝점 중심이 구멍 단면 안에 있는 프레임에서 20 mm를 기준으로 구분했다.

| Box | 구간 | 프레임 기존 → 파인튜닝 | 평균 오차 기존 → 파인튜닝 (mm) | P90 기존 → 파인튜닝 (mm) |
| --- | --- | ---: | ---: | ---: |
| 고정 | 전체 | 4,989 → 5,003 | 3.43 → 5.51 | 5.81 → 6.91 |
| 고정 | 삽입 전 | 4,377 → 4,230 | 2.91 → 3.01 | 5.18 → 4.63 |
| 고정 | 얕은 진입 | 371 → 550 | 9.80 → 25.83 | 25.01 → 67.33 |
| 고정 | 깊은 삽입 | 241 → 223 | 3.07 → 2.75 | 5.47 → 5.18 |
| 이동 | 전체 | 6,289 → 6,579 | 5.69 → 6.60 | 11.44 → 10.96 |
| 이동 | 삽입 전 | 4,909 → 5,157 | 3.86 → 4.87 | 8.09 → 7.61 |
| 이동 | 얕은 진입 | 823 → 778 | 7.88 → 14.61 | 13.07 → 71.89 |
| 이동 | 깊은 삽입 | 521 → 615 | 19.64 → 11.02 | 57.71 → 19.66 |

얕은 진입에서는 두 조건 모두 평균과 P90이 커졌다. 이동 Box에서는 전체 P90이 소폭 줄었지만 평균은 커졌다. 깊은 삽입까지 도달한 프레임에서의 P90은 57.71 → 19.66 mm로 줄었다.

저장된 Object21 벡터와 GT Hole 자세에서 횡방향 오차를 다시 계산해 로그 수치와 대조했다. 프레임 수와 집계값은 [검증 데이터](../../outputs/recurrent_final_gtfree/source_runs/verified.json)의 `object21_lateral`에 저장했다.

### 얕은 진입에서 50 mm 이상인 프레임

[앞단 단독 평가](gtfree_frontend_retrain.md)의 테스트에는 저장된 Expert 행동을 따라간 별도의 24개 궤적을 사용했다. 그중 얕은 진입 94프레임에서 최종 GNN의 횡방향 오차는 P90 4.55 mm, 최대 12.99 mm였다. 폐루프에서는 동일 체크포인트가 Mamba의 행동으로 생성된 관측을 처리했다.

| Box | 기존 Mamba 50 mm 이상 | 파인튜닝 Mamba 50 mm 이상 | 파인튜닝에서 집중된 시드 | 해당 시드를 양쪽에서 뺀 P90 기존 → 파인튜닝 |
| --- | ---: | ---: | --- | ---: |
| 고정 | 2 / 371 | 156 / 550 | 700732에 150프레임 | 25.07 → 24.41 mm |
| 이동 | 25 / 823 | 85 / 778 | 700882에 85프레임 | 12.70 → 10.91 mm |

파인튜닝 쪽 고정 700732의 해당 150프레임에서 절대 Peg 끝점 3D 오차 중앙값은 66.49 mm, Hole 중심은 1.77 mm였다. 이동 700882의 해당 85프레임은 각각 137.27 mm와 2.83 mm였고, 85프레임 내내 Peg 꼭짓점은 직접 검출되지 않았다. 이동 700882는 기존 Mamba에서도 같은 기준의 오차가 25프레임 있었지만 성공했고, 파인튜닝 Mamba에서는 실패했다. 이 비교는 P90이 어떤 시드에 민감한지 보여주는 사후 진단이다. 공식 성공률과 오차 집계에는 두 시드를 포함한다.
