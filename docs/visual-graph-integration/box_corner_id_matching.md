# RGB-D 검출 후보의 Box 외곽 꼭짓점 ID 매칭

## 범위와 구현

[기존 RANSAC 검출기](final_detector_transformer_eval.md)의 3D 후보와 Peg/Box 물체 종류를 사용해 Box 외곽에 물리적인 8개 꼭짓점 번호를 배정한다. 초기 자세 추정과 프레임별 배정에는 시뮬레이터 GT 좌표, GT 자세, segmentation, 물체 크기 또는 이동 스케줄을 개별 장면에서 읽어 오지 않는다. 채점은 별도 단계에서 GT와 비교한다.

고정된 작업 조건으로 테이블의 높이 (z=0), 정육면체 형태, 한 변의 허용 범위 170–250 mm, 초기 수평 각도 67.5°–112.5°, 이후 평행 이동을 사용한다. 지오메트리의 좌표 부호 `(±x, ±y, ±z)`에 대응하는 번호 순서는 기존 20 슬롯 Transformer를 학습한 때와 같다. 보고서의 꼭짓점 번호는 1–8이며 코드의 슬롯은 0–7이다.

첫 프레임의 Box 후보들을 사용해 상·하면 수준에 해당하는 점을 찾고, 여러 점 쌍을 모서리 또는 대각선으로 가정해 중심, 한 변 길이, 각도 후보를 만든다. 예상 꼭짓점과 검출 후보의 대응이 가장 많고 거리가 작은 자세를 고른 뒤 좌표를 다시 맞춘다. 이후에는 초기 각도 및 길이를 유지하고, 현재 대응점 세 개 이상이 합의하는 수평 이동량으로 중심을 갱신한다. 후보가 없거나 기준 거리 밖인 꼭짓점은 슬롯을 비운다. 서로 다른 슬롯의 거리 게이트는 겹치지 않아 후보 하나가 두 번호로 배정되지 않는다. 장기 미관측 후에는 관측된 점으로 초기화 조건을 다시 검사한다.

RGB-D는 기존 카메라와 이동 Box 시뮬레이션으로 다시 재생했다. 배정 거리 4, 6, 8, 10, 12, 15, 18 mm 중 검증 24개 장면에서 5 mm 이내 정확한 배정의 비율이 99% 이상이고 대응 가능점 재현율이 가장 높은 값을 선택한다. 99%에 도달한 후보가 없으면 정밀도와 대응 가능점 재현율의 조화평균 최대값을 선택한다. 임계값 선택과 별도로 미학습 테스트 32개 장면을 채점한다.

## 채점 지표

- **정확한 배정:** 선택한 검출 좌표가 배정된 GT 외곽점의 5 mm 이내다. 분모는 배정한 모든 점이다.
- **번호 뒤바뀜:** 선택 좌표가 다른 외곽점의 5 mm 이내에 있다. 어느 GT 외곽점에도 5 mm 이내로 대응되지 않는 후보는 별도 집계한다.
- **대응 가능점 재현율:** 원시 검출에 5 mm 범위의 일대일 대응이 존재하는 가시 외곽점 중, 올바른 번호로 배정한 비율이다. 이 일대일 대응은 원래 검출기 평가처럼 가시 외곽과 Hole을 함께 매칭하고 외곽 대응 슬롯만 세었다. 가시점 전체를 분모로 한 재현율도 기록한다.

## 결과

검증 24개 장면(2,706프레임)에서 6 mm를 선택했다. 검증에서 정확한 배정은 99.79%, 대응 가능점 재현율은 100%였다. 4 mm 기준은 정확한 배정이 100%였고 대응 가능점 재현율은 99.76%였다. 6 mm와 동률인 더 큰 임계값 중 작은 값을 선택했다.

| 테스트 구간 | 프레임 | 5 mm 이내 정확한 배정 | 다른 번호로 배정 | 검출 대응 가능점 회수 | 가시 외곽점 재현율 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 전체 | 3,352 | 18,882 / 18,902 (99.89%) | 0 | 15,233 / 15,233 (100%) | 94.97% |
| Box 이동 중 | 695 | 3,931 / 3,938 (99.82%) | 0 | 3,165 / 3,165 (100%) | 94.90% |
| 삽입 직전 | 160 | 823 / 828 (99.40%) | 0 | 671 / 671 (100%) | 96.41% |
| 첫 프레임 | 32 | 178 / 178 (100%) | 0 | 142 / 142 (100%) | 92.81% |

모든 테스트 장면에서 첫 프레임에 번호 배정을 시작했다. 총 18,902건 중 20건은 배정한 GT 지점에서 5 mm를 넘었고, 전체 거리 P90은 2.04 mm, 최대는 5.42 mm였다. 5 mm 이내에서 다른 외곽 번호로 배정된 사례는 0건이었다. 정확한 배정 수와 검출 대응 가능점 수의 분모는 다르다. 전자는 배정 좌표가 어느 물리 외곽점과 일치하는지 전체 외곽 GT로 검사했고, 후자는 RGB-D 가시성 판정을 통과한 점만 사용한다. 전체 8개 슬롯을 관측으로 채우는 것이 이 실험의 완료 조건은 아니며, 보이지 않거나 대응 가능한 검출이 없는 슬롯은 비울 수 있다.

## 적용 및 검증

실행은 에피소드마다 `BoxCornerMatcher(assignment_m=.006)`을 만들고 `step(box_xyz)`에 현재 프레임의 Box 계열 검출 좌표를 넣는다. 반환값은 GT와 같은 순서의 8개 슬롯에서 입력 후보 인덱스를 나타내며 `-1`은 미배정이다. 사용 방식 그대로 독립적으로 다시 돌려 검증·테스트 배정 파일과 인덱스가 모두 일치함을 확인했다.

합성 좌표에서 후보 순서 변경, 순간 가림, 혼동 후보, 각도 구간 양끝, 프레임당 6 mm 평행 이동을 검증했다. RTX 3090에서 기존 RANSAC 검출을 실행하고, 매칭은 CUDA 모델 학습 없이 CPU의 NumPy로 수행했다. 공통 ExperimentLogger 완료 상태, 해시, 테스트 시드와 프레임, 입력 좌표 보존, 일대일 대응과 지표를 확인했다. 이번 실험의 출력은 Box 외곽 ID까지다. Peg, Hole 입구, Transformer·GNN 연결 및 학습 분포 이외의 자세는 별도 평가 범위다.
