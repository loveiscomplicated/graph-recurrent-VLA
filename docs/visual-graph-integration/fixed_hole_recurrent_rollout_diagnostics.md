# Fixed Hole Recurrent rollout 오차 진단

최종 `ens_mamba5@step` 고정 Hole 평가의 원본 8개 JSONL을 팀 Hugging Face 모델 저장소 revision `c6afc41750ab0b4b215873d18a53b28ba407eb80`에서 읽었다. `env_seeds.json[150:350]`과 정확히 일치하는 고유 장면 200개를 확인했다. 성공 179개, 실패 21개다. MLP 조건은 분석에 포함하지 않았다.

## 원본 로그 분석

아래는 각 장면의 마지막 10개 행동 직전 프레임을 평균한 뒤, 장면별 평균의 중앙값을 구한 결과다. 실제 정렬은 마지막으로 저장된 행동 직전 프레임 하나에서 측정했다. 단위는 mm다.

| 지표 | 성공 179개 | 실패 21개 |
| --- | ---: | ---: |
| Graph 원본 Peg 위치 오차 | 2.38 | 17.56 |
| Graph 원본 Hole 위치 오차 | 2.00 | 6.16 |
| Graph 원본 Peg 끝점–Hole 상대 벡터의 3D 오차 | 3.85 | 34.90 |
| 필터 후 Peg 끝점–Hole 상대 벡터의 3D 오차 | 2.36 | 12.65 |
| 필터 후 Peg 끝점–Hole 상대 벡터의 횡방향 오차 | 2.00 | 11.28 |
| 실제 Peg 끝점–Hole 횡방향 거리, 마지막 관측 | 1.73 | 10.80 |

같은 장면의 3D 오차를 직접 짝지어 비교하면, 필터 후 오차가 감소한 경우는 성공 148/179개, 실패 19/21개다. 장면별 감소량의 중앙값은 각각 1.14mm, 14.28mm다. 원본 `err_mm`은 0.1mm, 필터 후 `fxyz_mm`은 축별 0.01mm로 반올림되어 있다. 이 비교는 동일 rollout 안에서 이미 계산된 입력을 분석한 결과다. 필터를 제거해 실행하는 정책 개입은 수행하지 않았다.

실패 21개 중 20개는 로그의 상승 기준을 만족했다. 성공 179개는 모두 Hole 근처 접근 trigger를 기록했고, 실패 21개는 해당 trigger가 없다. 따라서 위 표는 에피소드의 종료 부근을 요약하며, 성공과 실패가 같은 조작 단계에 있음을 전제로 하지 않는다.

원본 로그의 `err_mm`에는 Graph의 3D 오차 크기만 있어 원본 횡방향 오차를 복원할 수 없다. 필터 후 횡방향 오차는 `fxyz_mm`의 Y·Z 성분으로 계산했다. 이 추정 오차와 실제 횡방향 정렬 오차는 서로 다른 물리량이다.

## 같은 seed 네 장면 재실행

원본 성공군과 상승 기준을 충족한 실패군에서 각각 seed 오름차순으로 첫 두 장면을 골랐다. Mamba 디코더 5개는 최종 평가 백업에서 복원했다. Graph 쪽은 팀의 paired Recurrent 데이터 배포 manifest에서 Transformer 및 GNN 후보를 찾아 모델 백업 SHA-256과 대조했다. 원 평가의 `paths.json`이 없어서 평가에 쓴 Graph 가중치와 완전히 동일한 파일이라고 인증할 수 없다.

Vast.ai `60785391`의 RTX 3090에서 CPU PhysX와 CUDA RGB-D 렌더링을 사용했다. 현행 `graph` (`bb01149`)로 실행했을 때는 원본 성공 두 장면이 모두 실패했다. 최종 평가 백업이 가리키는 평가 코드 `f47789b`와 이전 카메라·검출기가 있는 기반 `2302bd2`를 별도 경로에 재구성하자 네 장면의 성공 여부와 스텝 수가 원본과 일치했다. 재실행과 저장 로그 간 최대 프레임별 원본 3D 오차 차이는 0.60–4.70mm, 필터 후 오차의 축별 최대 차이는 0.18–5.38mm였다. 전체 궤적의 수치 동일성은 확인되지 않았다.

기존 `run_job`과 `Ensemble`을 호출하며 action 직전의 Graph 원본 Object21, 필터 후 Object21, 같은 순간의 GT Object21과 파지 상태를 기록했다. 모든 앙상블 멤버의 필터 출력이 같음을 매 스텝 확인했다. 상대 벡터는 GT Hole 회전으로 같은 Hole 좌표계에 투영했다. 횡방향 추정 오차는 `‖(예측−GT)[Y,Z]‖`, 실제 횡방향 거리는 `‖GT[Y,Z]‖`로 계산했다.

## 검증과 산출물

- 원본 200개 seed 및 179개 성공을 확인했고, 필드별 스텝 길이를 대조했다. 재실행 4개의 성공 여부·스텝 수·trace 길이를 원본과 대조했다.
- 재실행은 공통 `ExperimentLogger`로 기록했다. W&B는 비활성화했다. 기존 평가·학습 코드는 수정하지 않았으며 외부 게시도 없었다.
