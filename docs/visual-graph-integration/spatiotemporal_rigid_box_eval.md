# 954에폭 Transformer에 Box 강체 평행 이동 보정 연결

## 조건

[954에폭 평가](spatiotemporal_corner_tracker_convergence.md)에서 저장된 RANSAC 검출 좌표와 Transformer 출력을 레퍼런스로 재사용했다. 테스트는 이동 Box 장면 32개(시드 3100144–3100175)와 3,352프레임이다. 해당 검출은 평가에서 GT로 꼭짓점 ID를 배정했다. 모델을 재학습하지 않고 [기존 강체 평행 이동 보정](rigid_box_tracking_eval.md)을 고정 ID 슬롯에 연결했다.

처음 검출된 Box 외곽·Hole 좌표를 그 슬롯의 기준 위치로 기억한다. 이전에 등록한 Box 외곽점 중 이번에 다시 관측된 점이 세 개 이상이고 그 이동량이 8 mm 이내에서 합의하면 공통 이동량을 갱신한다. 기존 구현의 최대 5프레임 속도 외삽과 최대 이동 속도 조건을 유지했다. 현재 검출된 점과 Peg 점, 한 번도 검출되지 않은 슬롯은 원본 Transformer 출력이 유지된다. 강체 보정은 과거에 최소 한 번 관측됐다가 현재 비어 있는 Box 외곽·Hole 슬롯의 좌표를 바꾼다.

32개 장면에서 실제 이동 중인 695프레임, 이동 후 580프레임, 각 장면의 삽입 직전 정렬 마지막 5프레임을 모은 160프레임을 구분했다. 이동 중 677프레임에서 외곽점의 관측 대응으로 평행 이동을 갱신했다. 이동 중 미검출 Hole 점 125개 중 124개 값이 바뀌었다. 삽입 직전 미검출 Hole 점은 122개 모두 바뀌었다.

## 3D 꼭짓점 결과

아래 P90은 같은 ID의 GT에서 예측까지의 3D 거리이며, 각 행에서 보정 전후 동일한 점을 사용했다.

| 구간·대상 | 표본 | Transformer 단독 P90 (mm) | 강체 보정 결합 P90 (mm) |
| --- | ---: | ---: | ---: |
| 전체 미검출점 | 20,961 | 7.03 | 6.37 |
| 이동 중 미검출 Box 외곽 | 2,395 | 6.77 | 4.76 |
| 이동 중 미검출 Hole 입구 | 125 | 18.58 | 4.29 |
| 이동 후 미검출 Hole 입구 | 238 | 6.70 | 2.99 |
| 삽입 직전 미검출 Box 외곽 | 609 | 9.27 | 6.87 |
| 삽입 직전 미검출 Hole 입구 | 122 | 6.93 | 2.99 |

이전 검출 기록이 있는 미검출 Hole 점만 보면 전 구간 362개에서 P90은 13.16 → 3.03 mm였다. 이전 검출 기록이 없는 점도 포함하면 전 구간 448개에서 19.84 → 19.16 mm였다. 좌표 보정의 효과는 이미 검출했던 Hole 점을 이어 추정하는 경우에 집중됐다.

## 같은 동결 GNN의 Object21 결과

두 입력은 동일한 20개 슬롯, TCP, 현재 관측 플래그를 사용한다. 이전과 같은 GT 혼합 학습 GNN을 동결하고 재실행했다. 횡방향은 Peg 끝점–Hole 중심 상대 벡터의 오차에서 GT Hole 축에 수직인 성분이다.

| Object21 지표 | Transformer 단독 P90 | 강체 보정 결합 P90 |
| --- | ---: | ---: |
| 이동 중 횡방향 오차 | 8.31 mm | 8.43 mm |
| 삽입 직전 횡방향 오차 | 8.70 mm | 8.74 mm |
| 삽입 직전 Hole 중심 위치 오차 | 8.35 mm | 8.28 mm |
| 삽입 직전 Hole 축 각도 오차 | 10.34° | 10.41° |

미검출 Box·Hole 좌표의 개선 폭에 비해 Object21의 오차 변화는 작았다. 이번 비교에서 GNN의 Object21 오차를 구성하는 요인별 기여는 분리하지 않았다. Box의 순수 평행 이동과 GT 기반 ID 배정 조건에서 실행했으며, 카메라 관측에 의한 실제 꼭짓점 연결, 회전, 폐루프 삽입 성공률은 별도 평가 범위다.

## 검증 및 산출물

RTX 3090에서 동결 GNN을 실행했다. 공통 ExperimentLogger의 완료 상태와 스크립트·가중치·입력 해시를 확인했다. 좌표 보정 전후에 현재 검출 좌표, Peg 좌표, 미등록 슬롯 좌표가 정확히 일치했다. 보정 전 GNN 출력을 기존 평가와 대조했고, 이동 중 Hole 오차와 삽입 직전 횡방향 오차 P90을 저장된 예측으로 다시 계산했다.
