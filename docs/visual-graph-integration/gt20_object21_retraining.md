# 시뮬레이터 GT20 입력으로 GNN 재학습

## 질문과 실험 설정

[시뮬레이터 전체 GT 입력 평가](full_sim_gt_direct_gnn.md)에서는 검출·추적값으로 학습한 GNN에 정확한 GT20을 입력해도 삽입 직전 횡방향 오차 P90이 13.68 mm 남았다. 이번 실험은 검출기와 추적기가 정확한 3D 점을 전달하는 조건에서 GNN 자체가 상태를 얼마나 정확하게 복원할 수 있는지 확인한다.

- 입력은 시뮬레이터 GT의 Peg 꼭짓점 8개, Box 외곽 8개, 앞쪽 Hole 입구 4개와 TCP 위치다. 20개 점을 모두 현재 관측으로 표시한다. Box 외곽과 Hole 입구는 같은 Box 유형이다. 물리 꼭짓점 ID는 입력하지 않는다.
- 기존 `graph_batch`와 `VertexEdgeGatedMPNN`을 재사용했다. hidden 64, 2개 메시지 패싱 층, dropout 0으로 유지했다. 두 모델 모두 테스트에서 동일한 GT20 그래프와 TCP를 받았다.
- 정답은 동일 프레임의 시뮬레이터 GT Object21이다. 기존 `object21_loss` 및 `run_epoch`를 재사용했다. 새 GNN은 모델 시드 0에서 무작위 초기화하고 AdamW, 초기 학습률 0.0003, batch size 96, gradient clipping 1.0으로 40에폭 학습했다. 최저 검증 손실의 40에폭 체크포인트를 선택했다. 비교 모델은 기존 검출·추적 캐시로 학습한 동결 체크포인트 `a1fd52b4ab53496693a8737596f92baf`다.
- CPU PhysX, `state_dict`와 scripted expert를 이용해 `PegInsertionSide-v1` 고정 Hole 장면을 새로 수집했다. 프레임을 순서대로 기록해 삽입 단계 진입 또는 최대 200스텝까지 수집했다. GPU는 RTX 3090, PyTorch 2.14.1+cu132다.

| 분할 | 시드 범위(포함) | 에피소드 | 프레임 |
| --- | --- | ---: | ---: |
| 학습 | 3100000–3100119 | 120 | 12,237 |
| 검증 | 3100120–3100143 | 24 | 2,589 |
| 테스트 | 3100144–3100175 | 32 | 3,315 |

테스트 시드는 새 모델 학습이나 체크포인트 선택에 사용하지 않았다. 테스트 32개는 모두 scripted expert의 삽입 단계에 진입했다. 삽입 직전 지표는 파지가 유지된 마지막 정렬 프레임을 에피소드마다 5개씩 사용했다. 이 실험에는 검출기, 추적기, KinFilter 및 Recurrent 모델의 행동 실행이 포함되지 않는다.

## 결과

### 삽입 직전 160프레임

각 셀은 중앙값 / P90이다. 축 각도는 GT와 예측의 로컬 +X 방향 사이 각도이고, 횡방향은 Peg 끝점–Hole 중심 상대 벡터 오차에서 GT 삽입축에 수직인 성분의 크기다.

| 지표 | 기존 GNN | GT20으로 재학습 |
| --- | ---: | ---: |
| Peg 중심 (mm) | 3.402 / 5.216 | 0.108 / 0.172 |
| Hole 중심 (mm) | 7.929 / 13.747 | 1.160 / 2.348 |
| Peg 축 (°) | 0.307 / 0.572 | 0.399 / 0.765 |
| Hole 삽입축 (°) | 3.459 / 5.276 | 1.027 / 2.501 |
| Peg 끝점–Hole 횡방향 (mm) | 7.033 / 13.529 | 0.998 / 2.096 |
| Peg 끝점–Hole 3D 상대 오차 (mm) | 7.823 / 14.655 | 1.027 / 2.188 |
| Peg 끝점 3D 위치 오차 (mm) | 8.051 / 11.209 | 0.897 / 1.355 |

전체 테스트 3,315프레임에서는 횡방향 P90이 16.704 → 2.752 mm였다. 첫 파지에서는 17.288 → 2.727 mm, 파지 유지·정렬 전체에서는 15.042 → 2.244 mm였다. 삽입 직전 횡방향 오차는 160/160프레임에서 줄었고, 기존 체크포인트가 원래 낮은 오차를 보였던 Peg 축에서는 삽입 직전 P90이 0.572 → 0.765°로 높아졌다.

정확한 GT20 입력에서 기존 그래프 표현과 GNN 구조로도 Peg 끝점 횡방향을 더 정확히 추정할 수 있었다. 비교 모델은 학습 데이터와 관측 분포, 학습 이력이 다르므로 이 비교만으로 개선폭을 GT 좌표의 정확도 한 요인에 배정할 수 없다. 실제 검출·추적 입력에서의 성능과 다른 초기화 시드의 분산은 이번에 측정하지 않았다.

## 소요 시간 및 검증

GT 데이터는 네 작업이 병렬로 수집했고 가장 긴 작업이 177.3초였다. 40에폭 학습과 테스트 추론은 241.5초에 완료됐다. GPU 원격 실행 기준으로 수집과 학습 합계는 약 7분이다. 공통 `ExperimentLogger`로 각 작업의 설정·지표·체크포인트를 기록했고 로컬 복사본을 보존했다.

데이터 해시, 176개 시드의 중복 부재, 20점 입력 모양, 체크포인트 선택, 테스트 예측의 유한성 및 최종 횡방향 수치를 검증했다. 횡방향 P50과 P90은 저장된 GT와 예측을 NumPy에서 따로 계산해 일치시켰다. 기존 GNN 구현과 시뮬레이터 코드는 편집하지 않았다.
