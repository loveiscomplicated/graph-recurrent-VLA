# Recurrent 최종 혼합 학습과 Graph 연동 검토

## 확인한 설정

공유된 Recurrent 최종 문서를 `graph2`의 `recurrent/exp2` 학습·실행 코드 및 Vast에 백업된 Mamba 체크포인트 5개와 대조했다. 각 체크포인트의 학습 설정은 1,000개 데모, 3,000 업데이트, 배치 8, 혼합 계수 0·0.25·0.5·0.75·1, TCP 6D, step 출력이다. 필터는 관측 Box 수 2개 이상과 Peg 수 5개 이상을 우선하는 평균 방식이다. 길이로 Peg 끝 위치를 덮는 prior는 최종 체크포인트 설정에 없다.

같은 시점의 `state36_gt`와 `state36_transformer`를 `GT + α × (Graph − GT)`로 보간한다. 수집 코드는 두 입력에 동일한 `robot15`를 넣으므로 보간으로 달라지는 부분은 물체 상태 21차원이다. 각 α 단계에 별도로 시간 필터를 적용하고 모델 입력을 변환한다. 한 업데이트에서 선택한 각 에피소드에 α를 하나씩 뽑아 전체 에피소드에 동일하게 적용하고, 원본의 expert action으로 모방 학습한다. 정규화 통계는 혼합 단계 전체를 이용한다. 실행 시 물체 상태에는 Graph 추정값이 들어오고, 로봇의 TCP와 그리퍼 등 로봇 상태도 함께 제공된다.

저장 형식은 `robot15 + Object21`의 36차원이다. 최종 체크포인트의 모델 입력은 44차원이다. 실행 코드에서 TCP quaternion 4차원을 6D 회전으로 바꿔 38차원으로 만들고, Hole 좌표계에서 본 Peg 끝점 위치 3개와 상대 회전 벡터 3개를 추가한다. 디코더는 각 체크포인트에 저장된 정규화 통계를 사용한다.

## 결과 해석

문서의 같은 필터 조건 비교에서 Mamba 성공률은 Graph 전용 학습 60%에서 혼합 학습 72%로 올라갔다. 개발 과정에서 사용한 30개 장면의 결과이며, 혼합의 효과를 보여주는 비교다. 이후 200개 결과에는 필터, 6D, step 출력 및 앙상블 구성이 함께 적용됐다. GT 학습·GT 평가의 91.3%와 최종 Graph 앙상블의 89.5%는 평가 구성과 조건이 달라 직접 우위를 주장할 수 없다.

보관된 최종 로그 8개에서 두 모델의 고정 Hole 결과 400개를 확인했다. 환경 시드 200개가 일대일로 대응됐다.

| 동일 환경 시드에서 비교 | 장면 수 |
| --- | ---: |
| Mamba와 MLP 모두 성공 | 148 |
| Mamba만 성공 | 31 |
| MLP만 성공 | 10 |
| 둘 다 실패 | 11 |

합계는 Mamba 179/200(89.5%), MLP 158/200(79.0%)이다. 불일치 41쌍의 정확 양측 McNemar 검정은 p=0.00145다. 이는 해당 200개 고정 Hole 장면과 해당 가중치의 비교이며 움직이는 Hole 결과를 포함하지 않는다.

## 새 Graph와의 연결

[새 GNN 결과](hybrid_input_gnn_finetune.md)의 이동 중 3.64 mm는 같은 시점의 GT를 기준으로 측정한 Object21 횡방향 P90이다. 이는 제어 성공률과 별개다. 기존 최종 디코더의 Hole 위치 필터는 과거 위치를 누적 평균한다. 체크포인트 설정에는 이동에 따라 누적 평균을 리셋하는 옵션이 없다. 이동 Box에는 이 필터의 영향을 비교하고, 학습과 실행에서 선택한 동일 필터를 적용해야 한다.

현재 새 GNN의 캐시와 테스트 예측에는 프레임별 Object21 GT와 Graph 추정값이 있으나 전체 robot15, expert action, Recurrent 학습용 에피소드 경계 및 검출 counts가 갖춰진 쌍 데이터 형식은 아니다. 해당 캐시는 삽입 진입 직전에 끝난다. 기존 파이프라인과 비교 가능한 디코더용 학습 데이터를 만들려면, 새 Graph 파이프라인으로 전체 데모의 같은 프레임에 `state36_gt`, `state36_transformer`, `expert_action`, `episode_offsets`, `counts`를 보존한다. 재학습 때 혼합 단계와 필터를 적용한 입력에서 정규화 통계를 다시 계산한다.
