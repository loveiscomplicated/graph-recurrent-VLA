# GT20 재학습 GNN을 검출·추적 입력에 연결한 평가

## 비교 조건

[GT20 재학습 실험](gt20_object21_retraining.md)에서 정확한 20점을 입력한 테스트 시드 3100144–3100175를 재생했다. 같은 Main 카메라(새 위치) RGB-D와 scripted expert 궤적을 사용했다. 프레임 순서, expert 단계, 파지 상태와 GT Object21을 저장된 자료와 대조했다.

- **검출기:** `2b6c40e`의 `TorchCornerDetector.main(device="cuda:0", plane_fit_method="ransac")`를 사용했다. CUDA 검증 컴파일 기본값과 NumPy RGB-D 입력을 유지했다. RANSAC 선택은 [grid 비교](hole_detector_cuda_regression.md)의 Hole 입구 매칭 및 21D 재현을 근거로 했다.
- **추적기:** 기존 리더보드 집계가 우수한 동결 Transformer seed-0 체크포인트 및 `DetectedCornerTracker`의 30 mm 매칭 기준을 썼다. 두 GNN에 검출·추적 좌표, 관측 플래그, TCP 및 그래프를 동일하게 제공했다.
- **비교 모델:** 일반 검출·추적 캐시로 학습한 기존 GNN과 정확한 GT20으로 40에폭 재학습한 GNN이다. 양쪽 가중치를 동결했다. 이전 GT20 평가에서도 체크포인트 쌍은 같다.
- **지표의 범위:** 오프라인 Object21 오차다. 로봇은 scripted expert가 움직였다. TAPNext++, 필터, Recurrent와 폐루프 성공률은 이번 평가에 포함하지 않았다. 모든 검출기·추적기 조합을 탐색한 비교는 아니다.

삽입 직전은 삽입 단계에 진입한 에피소드별 마지막 다섯 파지 중 정렬 프레임이다. 횡방향 오차는 예측과 GT의 Peg 끝점–Hole 중심 벡터 차이를 GT 삽입축에 수직인 평면으로 투영한 크기다.

- 검출·추적 입력에서 GT20 재학습 모델은 삽입 직전 160프레임 모두에서 기존 모델보다 횡방향 오차가 컸다. 에피소드별 평균 차이를 같은 비중으로 계산하면 +43.50 mm였고 seed 단위 5,000회 재표집 95% 구간은 +37.71 ~ +49.31 mm였다.
- 초기 프레임에는 node의 관측 표시가 모두 켜져 있다. 이 구간에도 횡방향 P90은 검출·추적 입력에서 기존 15.18 mm, 재학습 77.56 mm였다. 추적 이력이 쌓이기 전부터 차이가 있었다. 삽입 직전 제공된 track은 중앙값 25개, 현재 관측은 17개다. 점 수와 구성, 관측 표시가 고정된 정확한 20점으로 학습한 조건과 달랐다. 각 요소의 영향을 따로 분리하지는 않았다.
- 정확한 GT20에서 확인한 성능은 검출·추적 입력에 그대로 전이되지 않았다. 기존 가중치와 재학습 가중치의 비교 결과이며, GT20 사전학습 후 실제 입력으로 미세조정하는 비교는 수행하지 않았다.

## 실행 기록과 산출물

RTX 3090에서 CPU PhysX, CUDA RGB-D 렌더링과 추론을 사용했다. 8개 시드씩 네 작업을 병렬로 수행했고 가장 긴 작업은 약 251초였다. 두 모델의 가중치와 이전 테스트 파일 SHA-256, 테스트 시드·프레임 정렬, 결과 크기 및 유한값을 검증했다. `ExperimentLogger`로 원격 실행을 기록하고 로컬에서 독립적으로 지표를 집계했다. 공유 모델 코드, 가중치 및 시뮬레이터 설정의 기본값을 편집하지 않았다.
