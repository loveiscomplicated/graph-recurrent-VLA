# 이동 Box의 강체 이동량을 사용한 3D 꼭짓점 보완

## 목표와 조건

[기존 이동 Box 검출·추적 평가](moving_box_detector_tracking_eval.md)의 동일한 32개 시드와 새 Main 카메라를 사용한다. RANSAC 꼭짓점 검출기와 Transformer 추적기의 가중치 및 거리 기반 데이터 연결을 고정했다. Box 점 중 현재 검출과 매칭된 좌표는 그대로 제공한다. Box만 평행 이동하는 검증 조건에서 현재 미검출인 Box·Hole 점을 보완한다. Peg와 회전은 이 실험에서 강체 보정의 평가 범위에 포함하지 않았다. GNN 및 Recurrent는 실행하지 않았다.

시험 구현은 track이 처음 관측될 때 해당 점을 Box의 추정 이동량에 대한 상대 좌표로 저장한다. 이후 현재 관측된 Box 외곽점의 대응에서 공유 평행 이동을 산출한다. 8 mm 안에서 합의하는 대응이 3개 이상일 때 좌표 성분별 중앙값으로 갱신한다. 평균 이동 속도가 프레임당 12 mm보다 크면 갱신을 거른다. Hole 검출기로 분류한 점은 Box 이동량을 구하는 관측에서 제외했다. Box 분류에는 검출기 메타데이터를 사용했으며, GT를 보정이나 데이터 연결에 사용하지 않았다.

- **Transformer**는 기존 미검출 점 예측이다.
- **Box 공통 이동**은 Box의 추정 이동을 해당 Box의 미검출 점에 동일하게 적용하고, 유효한 관측 대응이 없는 구간에는 마지막 Box 위치를 유지한다.
- **Box 공통 이동 + 속도**는 같은 강체 방식에 좌표 갱신에서 계산한 속도를 더한다. 유효한 관측이 끊기면 최대 5스텝까지만 외삽한다. 이후에는 그 위치를 유지한다.

합의점 개수와 마지막 관측 기반 갱신 후 경과 스텝은 같이 저장했다. 현재 측정값은 보존하므로 제공되는 모든 점에 정확한 직육면체 또는 정사각형 위치를 강제하지는 않는다. 등록된 미검출 점에만 공통 이동을 적용한다. 기존 체크포인트와 추적 결과를 사용하는 프로토타입을 별도 코드로 추가했다.

## 지표

공통 표본은 현재 관측이 끊긴 track 가운데, 과거 관측에서 가시 GT와 5 mm 이내 일대일 매칭으로 물리 ID를 한 번 연결할 수 있었던 점이다. 이 GT ID를 고정해 같은 점과 같은 프레임에서 모든 방법의 3D 위치 오차를 계산했다. 3 mm와 10 mm 가시점 재현율은 이전 평가와 같은 점 집합과 방법으로 계산했다. 이 점수는 복원된 미검출 좌표의 후보까지 포함한다.

## 결과

32개 궤적 3,352프레임의 재생과 GT를 확인했다. 기존 실행과 비교해 각 프레임의 Hole 앞쪽 3 mm 매칭 수가 모두 일치했다. 실제 이동 중 695프레임의 결과다.

| 현재 미검출인 점 | 평가 표본 | 기존 Transformer 중앙값 / P90 (mm) | Box 공통 이동 중앙값 / P90 (mm) |
| --- | ---: | ---: | ---: |
| 앞쪽 Hole 전체 | 349 | 16.40 / 45.46 | 2.05 / 3.00 |
| 앞쪽 Hole 중 가시 GT 기준을 충족하지 않은 점 | 46 | 20.75 / 76.71 | 2.72 / 7.71 |
| Box 외곽 전체 | 797 | 11.65 / 59.93 | 1.75 / 3.37 |

같은 미검출 Hole 표본에서 343/349개의 오차가 줄었고, 10 mm 이내 비율은 108/349에서 349/349로 늘었다. 가시 Hole 입구 기준 3 mm 재현율은 85.59%에서 88.69%로 높아졌고, 3 mm 이내 매칭이 0개인 프레임은 32/695에서 5/695로 줄었다. Box 공통 이동량의 GT 대비 P90은 0.21 mm다. 이 값은 Box 자세 이동량이며 꼭짓점 좌표 자체의 오차와 구분한다.

### 관측이 모두 끊기는 경우

실제 이동 중 695프레임 모두에서 Box 외곽 대응점 세 개 이상의 유효 갱신이 가능했다. 따라서 실제 재생의 속도 예측 켜짐·꺼짐 결과는 일치했다.

별도로 저장된 Box 이동량 갱신을 1, 3, 5스텝 동안 인위적으로 가리고, 마지막 위치를 유지하는 방식과 갱신 직전 속도를 유지하는 방식을 비교했다. 아래는 3스텝 차단 시점의 Box 위치 GT 대비 오차 P90이다.

| 차단 중 GT 이동 상태 | 시작점 수 | 마지막 위치 유지 (mm) | 속도 외삽 (mm) |
| --- | ---: | ---: | ---: |
| 계속 이동 | 599 | 17.22 | 2.13 |
| 차단 중 정지 | 96 | 7.38 | 14.06 |

이는 저장된 변위 갱신을 사용한 차단 시뮬레이션이다. 실제 전체 가림의 검출 및 track 재연결을 재생하지 않았으며 시작점 사이에 중복 프레임이 있다. Box가 계속 움직이는 동안에는 속도 예측이 도움이 됐고, 정지가 관측에서 숨겨지면 예측이 지나쳤다.

## 검증 및 산출물

RTX 3090에서 CPU PhysX, CUDA RGB-D 렌더링, RANSAC 및 기존 Transformer를 실행했다. NumPy 장난감 입력에서 외곽 오검출점 거르기, 현재 검출 좌표 유지, 미검출 Hole 동시 이동과 최대 5스텝 속도 외삽 제한을 확인했다. 32개 실장면에서 검출 좌표의 유지, 시드·프레임·가시성·Box 변위 정렬과 평가 코드 해시를 검증했다. 공통 실행 코드는 변경하지 않았고 학습·회전·Peg 강체 보정 및 GNN 추론은 이 결과에 포함하지 않았다.
