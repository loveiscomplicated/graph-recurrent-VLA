# 새 앞단과 재학습 Mamba의 고정·이동 Box 실패 분류

[최종 폐루프 평가](recurrent_full_insertion.md)의 원본 64개 롤아웃에서 고정 11개와 이동 18개 실패를 모두 확인했다. 29개 모두 마지막까지 Peg를 쥔 상태로 250스텝 한도에 도달했다. 이동 실패 18개에서 Box는 모두 실제로 움직였다.

깊이는 GT Peg 끝점 **중심**의 입구 면 기준 삽입축 좌표다. 최대 깊이는 중심의 y·z가 모두 구멍의 개구부 범위에 들어온 프레임에서만 계산했다. 이 기준은 끝점 중심을 분류하며 Peg 단면 전체의 정렬, 접촉이나 걸림까지 판정하지 않는다. 입구 면 ±0.1 mm는 경계, 0.1 mm 초과부터 3 mm 이하는 얕은 진입, 3 mm 초과부터 20 mm 이하는 중간 진입이다. 20 mm를 넘겨 들어갔을 때 마지막 깊이가 최고값보다 10 mm 이상 줄었거나 끝점 중심이 개구부 범위를 벗어나면 후퇴로 기록했다.

| 실패 유형 | 고정 11개 | 이동 18개 |
| --- | ---: | ---: |
| 끝점 중심이 개구부 범위에 들지 않음 | 0 | 1 |
| 입구 면 앞에서 정체 | 4 | 2 |
| 입구 면 경계 | 3 | 2 |
| 얕은 진입 | 4 | 8 |
| 중간 깊이 진입 | 0 | 0 |
| 깊은 진입 후 후퇴 | 0 | 2 |
| 깊은 진입 후 유지·정체 | 0 | 3 |

고정 Box 실패 전체의 최대 깊이는 0.74 mm였다. 이동 Box에서 깊이 20 mm를 넘긴 실패 5개 중 700831은 29.39 mm에서 −17.91 mm로 입구 밖에 빠졌고, 700882는 33.74 mm에서 5.68 mm로 후퇴했다. 700687, 700732, 700806은 깊이를 대체로 유지했지만 성공 깊이에는 각각 10.19, 11.91, 10.05 mm 못 미쳤다.
