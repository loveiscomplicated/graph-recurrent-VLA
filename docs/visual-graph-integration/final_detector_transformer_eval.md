# 최종 CUDA 기본 검출기와 954에폭 Transformer의 꼭짓점 3D 오차

## 조건

`graph2` 브랜치의 `b2e8e4c`에서 `TorchCornerDetector.main(device='cuda:0')`을 실행했다. 이 커밋에서 CUDA 기본 평면 추정기는 Grid다. [954에폭 Transformer](spatiotemporal_corner_tracker_convergence.md)는 RANSAC 검출 좌표로 학습했으므로 이번에는 같은 모델을 동결하고 Grid 검출로 입력을 바꿨다. 테스트 장면은 기존 새 Main 카메라와 이동 Box 32개 시드(3100144–3100175)이며 원본 RGB-D를 다시 생성했다.

검출기는 가변 개수의 3D 후보와 Peg·Box 물체 종류를 출력한다. 일부 Hole 후보에는 검출 방식 및 Hole 윤곽 메타데이터가 있다. 물리 꼭짓점 번호는 이 출력에 포함되지 않는다. 고정 ID Transformer에 좌표를 입력하기 위해 평가에서 가시 GT 꼭짓점과 같은 물체 종류의 후보를 5 mm 이내에서 일대일로 매칭했다. Peg 8점, Box 외곽 8점, Hole 입구 4점의 20개 슬롯을 사용했다. 관측된 슬롯에는 원시 검출 좌표가 유지되고, 대응이 없는 슬롯은 모델이 추정했다. 현재 가려진 점과 가시하지만 5 mm 이내 대응이 없는 점은 모두 미검출에 속한다.

3D 오차는 월드 좌표에서 각 출력과 같은 ID의 GT 사이의 유클리드 거리다. 검출점 오차의 표본은 5 mm 이내에서 대응을 확인한 점이다. 검출기의 가시점 재현율은 3/5/10 mm별 일대일 매칭으로 별도 집계했다. GT 기반 매칭은 슬롯에 넣을 후보를 선택하는 데도 쓰이므로 자동 ID 배정의 성능과 구별된다.

## 결과

RTX 3090에서 32개 테스트 장면의 3,352프레임을 재생했다. 최종 3D 출력은 프레임마다 20점이고 총 67,040점이다. 이 중 45,074점은 최종 검출기의 좌표를 그대로 사용했고 21,966점은 Transformer가 추정했다. 5 mm 이내로 GT에 대응한 검출 슬롯은 프레임당 평균 13.45개였고, 삽입 직전에는 12.56개였다.

| 평가 범위 | 최종 20점 전체 P90 (mm) | 검출이 대응된 점 P90 (mm) | Transformer가 채운 점 P90 (mm) |
| --- | ---: | ---: | ---: |
| 전체 3,352프레임 | 4.25 | 2.33 | 9.13 |
| Box 이동 중 695프레임 | 5.62 | 2.36 | 12.79 |
| 삽입 직전 160프레임 | 6.91 | 2.30 | 10.93 |

삽입 직전 160프레임에서의 점 종류별 결과다. 검출 재현율의 분모는 가시 GT, 좌표 오차는 위에서 정의한 점 집합을 사용했다.

| 대상 | 가시점 3 mm 검출 재현율 | 관측점 P90 (mm) | 미검출점 표본 | Transformer P50 / P90 (mm) |
| --- | ---: | ---: | ---: | ---: |
| Peg 꼭짓점 | 94.04% | 1.58 | 399 | 5.53 / 11.81 |
| Box 외곽 | 94.25% | 1.81 | 609 | 4.27 / 9.42 |
| Hole 입구 | 77.39% | 2.86 | 182 | 4.12 / 74.32 |

Hole 입구의 삽입 직전 미검출점 182개 중 과거 검출이 있었던 142개의 P90은 6.82 mm였다. 이전에 한 번도 대응된 검출이 없는 40개의 P90은 108.24 mm였다. 후자는 시드 3100155 및 3100166에서 각각 4개 슬롯 모두가 마지막 5프레임까지 관측되지 않은 경우다. 같은 160프레임에서 GT 5 mm 기준으로 Hole 점이 하나도 대응되지 않은 프레임은 Grid 24개, 이전 RANSAC 9개였다.

같은 Transformer를 사용해 삽입 직전 **두 검출기 모두에서 미검출된** Hole 입구 122개만 비교하면 Grid P90은 6.81 mm, RANSAC P90은 6.93 mm였다. 각 검출기의 미검출을 모두 포함하면 Grid의 74.32 mm와 RANSAC의 6.93 mm가 나온다. Grid에서 미검출로 추가 분류된 점과 이전 관측 이력 차이를 포함한 결과다. 큰 오차가 어떤 후보 누락 경로에서 생겼는지는 이번에 나누지 않았다.

## 대응 상태 및 산출물

Transformer는 고정 물리 슬롯을 받지만, 현재 검출기의 반환값이 그 슬롯을 자동으로 채우지는 않는다. 실험에서 GT와 일대일 대응이 확인된 후보만 해당 슬롯에 넣었다. 자연 가림으로 보이지 않는 점과 관측됐더라도 GT에 대응하지 못한 후보가 있기 때문에 20개 슬롯이 모두 관측됐다고 해석할 수 없다. 실제 카메라 입력만으로 물리 ID를 배정하는 모듈은 이번 실행의 범위 밖이다.

공통 ExperimentLogger의 완료 상태 및 검출기와 체크포인트 해시를 확인했다. 기존 평가와 시드·스텝·GT 좌표·가시성 집합을 정렬했고, 관측점이 그대로 유지됨을 확인했다. 로컬 NumPy에서 검출 재현율과 3D 오차를 다시 계산했다. 시뮬레이션은 CPU PhysX, 렌더링·검출·Transformer는 CUDA에서 실행했다. `visual` 브랜치에는 다른 검출기 구현이 있으며 이 보고서는 `graph2` CUDA 기본 설정의 결과다.

- [집계와 실행 ID](../../outputs/final_detector_transformer_eval/source_runs/eval/summary.json)
- [프레임별 검출·추정 좌표 및 GT](../../outputs/final_detector_transformer_eval/source_runs/eval/predictions.npz)
- [재생·검출](../../outputs/final_detector_transformer_eval/collect_final.py) · [고정 ID 평가](../../outputs/final_detector_transformer_eval/evaluate_final.py) · [독립 검증](../../outputs/final_detector_transformer_eval/verify.py)

예측 NPZ는 프레임별 `seed`, `step`과 `xyz_final`, `xyz_gt`(3,352 × 20 × 3, 월드 좌표, m), `observed`, `previously_seen`을 포함한다. 슬롯 순서는 Peg 1–8, Box 외곽 1–8, Hole 입구 1–4다. `raw_xyz`는 검출기의 모든 후보를 프레임 순서로 이어 붙였으며 `raw_count`로 각 프레임의 범위를 찾을 수 있다.

## RANSAC 검출 결과로 같은 모델을 평가

학습과 동일하게 `plane_fit_method='ransac'`으로 수집한 [954에폭 평가의 저장된 검출 좌표와 예측](../../outputs/spatiotemporal_corner_tracker_convergence/source_runs/train/test_predictions.npz)을 사용했다. 시드·스텝·GT 월드 좌표와 가시점 집합이 위의 Grid 평가와 같음을 확인하고, 원시 검출 좌표가 유지되는지도 확인했다. Grid 때와 같은 집계로 3D 거리를 다시 계산했다.

| RANSAC 평가 범위 | 최종 20점 전체 P90 (mm) | 5 mm 안에서 대응한 검출점 P90 (mm) | Transformer가 채운 점 P90 (mm) |
| --- | ---: | ---: | ---: |
| 전체 3,352프레임 | 3.83 | 2.33 | 7.03 |
| Box 이동 중 695프레임 | 4.98 | 2.38 | 9.52 |
| 삽입 직전 160프레임 | 6.29 | 2.37 | 9.67 |

| 삽입 직전 점 종류 | 관측점 P90 (mm) | Transformer가 채운 점 P90 (mm) | 미검출점 수 |
| --- | ---: | ---: | ---: |
| Peg | 1.52 | 11.18 | 377 |
| Box 외곽 | 1.88 | 9.27 | 609 |
| Hole 입구 | 3.11 | 6.93 | 122 |

RANSAC은 삽입 직전에 프레임당 평균 13.08개 점을 GT와 대응시켰고, 미검출 Hole 입구 122개는 모두 이전 프레임에 한 번 이상 대응이 확인됐다. Box 이동 중 미검출 Hole 입구 P90은 18.58 mm였다. 이 집계는 이전 실험의 저장된 예측을 사용했으며, 꼭짓점 ID는 동일한 평가용 GT 기반 매칭을 따른다.
