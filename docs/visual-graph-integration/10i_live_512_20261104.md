# 10-I: live 두 카메라를512×512로 변경 — 2026-11-04

live `graph.plan_a_bc.rollout.environment`에서 **base_camera와 hand_camera 모두
512×512로 렌더링**하도록 변경했다. RGB·Depth는 이전에 연결한 native CUDA
출력을 유지한다. 설치된 ManiSkill의 센서 설정 API를 사용해 카메라 생성
단계에서 해상도를 지정했다.

VastAI **58752018 / RTX3090**에서 실제 reset1회와 zero-action step2회를
실행했다. 두 카메라 모두 RGB `[512,512,3]`, raw Depth `[512,512]`의 CUDA
텐서를 반환했고, intrinsic과 live 센서 어댑터도 검증했다. CUDA 테스트7개가
모두 통과했다.

## 변경 범위

공통 [simulator factory](../../envs/maniskill/peg_insertion.py)에 선택 인자
`sensor_configs=None`을 추가했다. 지정한 값만 ManiSkill `gym.make`에
그대로 전달하며, 생략한 기존 호출의 센서 기본값은 유지한다.
별도의 simulator 생성기나 카메라 인터페이스를 만들지 않았다.

[live environment](../../graph/plan_a_bc/rollout.py)는 다음 값을 사용한다.

```python
sensor_configs={
    'base_camera': dict(width=512, height=512),
    'hand_camera': dict(width=512, height=512),
}
```

ManiSkill3.0.1 `BaseEnv._setup_sensors`에서 task/agent 카메라에 이 override를
적용한 뒤 sensor를 생성하는 구현을 확인했다. `Camera.get_params`와
`RenderCamera.get_intrinsic_matrix`도 설치 소스에서 확인했다.
기존 카메라의 pose/FOV 설정은 유지하며 해당 해상도의 intrinsic을 렌더러에서
받는다. CPU PhysX, CUDA 렌더러·관측 출력,250-step horizon과 action/controller
설정은 유지했다. 학습 데이터 생성이나 기존 저장 데이터·캐시 변환은 수행하지 않았다.

## 실제 출력과 검증

| 카메라 | RGB | signed-mm Depth | 장치 |
| --- | --- | --- | --- |
| base_camera |512×512×3, uint8 |512×512, int16 | CUDA |
| hand_camera |512×512×3, uint8 |512×512, int16 | CUDA |

이번 실행에서 두 카메라의 intrinsic은 다음과 같았다.

```text
[[256,   0, 256],
 [  0, 256, 256],
 [  0,   0,   1]]
```

관측 intrinsic이 실제 renderer camera API의 행렬과 정확히 일치하고,
principal point가 `[256,256]`인지 reset/step마다 검사했다.
또한 다음 기존 GPU 출력 계약을 함께 확인했다.

- raw reset/step 관측의 모든 tensor leaf가 CUDA다.
- RGB/Depth는 관측 출력 wrapper 이전부터 CUDA이며 wrapper 후 pointer가 같다.
- live `sensors`에서 이미지 CPU 변환을 금지한 상태로 정상 실행된다.
- 반환된 `TensorCameraObservation`은512 출력과 값·dtype가 정확히 같고,
  다음 renderer 갱신에 영향받지 않도록 별도의 GPU image buffer를 소유한다.
- 물리는 `physx_cpu`/CPU, 렌더러는 `sapien_cuda`, horizon은250이다.

[기존 live 관측 테스트](../../graph/plan_a_bc/test_live_observation_output.py)에
512 출력 크기·intrinsic 검사를 추가했다. 기존 native CUDA 출력 및 raw observation
계약을 재사용한 Vast 테스트7개는 실패0/skip0이었다.
[공통 factory 테스트](../../tests/test_maniskill_env.py)는 센서 override를 생략하면
전달하지 않고, 지정하면 그대로 전달하는 계약을 추가로 확인한다.

로컬 macOS에서는 simulator/관측/live 관련14개 중11개 통과, CUDA 전용3개 skip이었다.
CUDA 렌더러 실행 증거는 Vast에서 얻었다. Terra API, 실제 SAM2 추론, Graph 전체
재측정·학습·정책 성능 평가는 이번 해상도 변경 검증에 포함하지 않았다.
