# 꼭짓점 ID 고정과 강체 내부 관계를 사용한 Transformer 추적기

## 목표 및 범위

꼭짓점 ID 대응을 통제한 상태에서, 시간 정보에 더해 현재 프레임의 같은 강체 점을 함께 보면 미검출 꼭짓점의 위치가 개선되는지 확인했다. [검출기 단독 실험](moving_box_detector_tracking_eval.md)의 RANSAC RGB-D 검출기를 그대로 사용했다. Peg는 8개, Box 외곽은 8개, 앞쪽 Hole 입구는 4개의 물리 꼭짓점 ID를 사용했다. Box 외곽과 Hole 입구는 하나의 강체 그룹이다.

현재 검출 후보를 같은 물체에 속한 카메라 가시 GT 꼭짓점과 5 mm 이내에서 일대일로 짝지어 ID 슬롯에 저장했다. 슬롯 좌표에 저장한 것은 검출기 자체의 3D 출력이다. 그 프레임에 매칭이 없는 슬롯은 미검출로 표시했다. 학습 정답은 가림 여부와 관계없이 해당 프레임의 시뮬레이터 GT 좌표다. 이 실험에서 GT를 쓰는 곳은 ID 매칭, 학습 정답, 채점이다. 테스트에서도 GT로 ID를 매칭했으며, 실제 배포에서 카메라 관측만으로 ID를 배정하는 구성은 아직 검증되지 않았다. GT와 대응시킬 수 없는 검출 후보는 모델 입력에서 배제했다.

[기존 이동 Box 실험](moving_box_gt20_training.md)과 같은 분할에서 시드 3100000–3100119를 학습에, 3100120–3100143을 검증에, 3100144–3100175를 테스트에 사용했다. 테스트의 검출 좌표와 관측 플래그는 [좌표·점 구성 분리 실험](gt_corner_input_ablation.md)의 저장된 프레임을 재사용했다.

## 모델 및 검증

세 모델은 같은 가중치 초기화 시드, 입력, 폭 48, 헤드 4개, causal 시간축 블록 2개와 공간 attention 블록 하나를 사용했다. 시간축 모델은 공간 attention에서 자기 슬롯만 보도록 제한했다. 공간·시간 모델은 같은 강체의 모든 슬롯을 허용했다. 마지막 모델은 같은 강체의 점 사이 예측 거리를 각 장면의 GT 거리와 비교하는 손실을 가중치 0.25로 추가했다.

입력은 슬롯 ID, 동일 슬롯의 마지막 검출 좌표, TCP 상대 위치, 현재 검출 여부 및 마지막 검출 이후 시간이다. 아직 한 번도 잡히지 않은 슬롯에는 학습 세트에서 계산한 슬롯별 평균 좌표를 기준점으로 사용했다. 관측 슬롯은 원래 검출 좌표를 유지하고, 미검출 슬롯의 현재 좌표만 예측한다. 모델은 현재·과거 프레임을 읽고, 테스트에서는 미래 프레임을 바꿔도 앞부분의 예측이 유지되는지 확인했다.

학습은 미검출 좌표 Smooth L1, AdamW, 학습률 0.0003, 최대 36에폭으로 진행했다. 검증 미검출 평균 3D 오차가 가장 낮은 체크포인트를 선택했다. 평가는 미검출 전체와 그중 과거 관측이 있었던 점을 따로 집계했다. 또한 모델별 20점 출력으로 이전 GT 혼합 GNN을 고정한 채 Object21을 예측했다. 이 비교에서는 현재 검출 플래그를 전달하고, 플래그만 전부 켠 조건도 별도로 집계했다.

## 결과

Vast.ai RTX 3090에서 학습용 120개 장면 13,448프레임과 검증용 24개 장면 2,706프레임을 수집했다. 테스트는 32개 장면 3,352프레임이고, 그중 695프레임에서 Box가 실제 이동했다. 미검출 꼭짓점 표본은 전체 20,961개, 이동 중 4,254개, 삽입 직전 5프레임씩 모은 160프레임에서 1,108개다. 마지막 검출 유지 대조에서는 한 번도 검출되지 않은 슬롯에 학습 세트 평균 좌표를 사용한다.

### 미검출점 3D 거리 오차 P90 (mm)

| 모델 | 전체 미검출점 | 이동 중 Box 외곽 | 이동 중 Hole 입구 | 삽입 직전 전체 미검출점 |
| --- | ---: | ---: | ---: | ---: |
| 마지막 검출 유지 | 139.36 | 98.86 | 32.87 | 175.77 |
| 점별 시간 Transformer | 97.74 | 100.30 | 34.67 | 96.46 |
| 공간·시간 Transformer | 33.74 | 24.28 | 30.22 | 35.37 |
| 공간·시간 + 강체 거리 손실 | 35.12 | 24.75 | 30.84 | 35.16 |

공간 attention을 허용했을 때 가장 큰 개선은 Box 외곽이었다. 이동 중 Box 외곽 미검출점 P90은 100.30 → 24.28 mm였다. 같은 조건에서 Hole 입구는 34.67 → 30.22 mm였다. 삽입 직전 Hole 입구 P90은 시간 모델의 17.25 mm에서 공간·시간 모델의 29.33 mm로 커졌다. 검증 미검출 평균 오차는 각각 48.47, 21.99, 22.12 mm였고 세 최고 체크포인트 모두 36에폭에서 나왔다. 이번 초기화 시드 및 학습 예산에서는 거리 손실을 추가해 전체 P90을 더 낮추지 못했다.

### 기존 강체 평행 이동 프로토타입과 같은 표본 비교

기존 추적 결과에서 GT와 신원이 연결된 미검출점 중 Box 이동 중인 표본만 비교했다. 기존 강체 보정이 일단 추적된 점에 적용되는 조건이므로, 이전에 한 번도 대응하지 못한 점은 이 표에 들어가지 않는다.

| 방식 | Box 외곽 P90 (668개, mm) | Hole 입구 P90 (106개, mm) |
| --- | ---: | ---: |
| 기존 Transformer + 평행 이동 보정 | 3.38 | 4.45 |
| 점별 시간 Transformer | 45.55 | 36.05 |
| 공간·시간 Transformer | 24.22 | 30.58 |
| 공간·시간 + 강체 거리 손실 | 23.68 | 31.79 |

현재 평행 이동 조건에서 이미 관측된 Box·Hole 점을 이어가는 것은 기하 보정이 더 정확했다. 새 모델은 이전에 미관측인 슬롯도 출력하지만 이 슬롯군에서 기존 기하 보정과 동일한 표본 비교는 성립하지 않는다. 회전과 전체 가림을 별도로 제어하는 실험은 진행하지 않았다.

### 동결 GNN의 Object21 오차 P90

아래 표는 각 추적기에서 20개 좌표를 만들고, 실제 현재 관측 여부를 함께 제공한 결과다. GT 기준은 20개 GT 좌표와 전체 관측 플래그를 사용한다.

| GNN 입력 | Box 이동 중 횡방향 (mm) | 삽입 직전 횡방향 (mm) | 삽입 직전 Hole 중심 (mm) | 삽입 직전 Hole 축 (°) |
| --- | ---: | ---: | ---: | ---: |
| GT 꼭짓점 | 2.86 | 2.67 | 2.82 | 1.87 |
| 점별 시간 Transformer | 29.74 | 31.10 | 37.57 | 20.19 |
| 공간·시간 Transformer | 18.21 | 17.12 | 16.86 | 12.72 |
| 공간·시간 + 강체 거리 손실 | 20.97 | 17.61 | 15.63 | 11.73 |

횡방향은 GT의 삽입축에 수직한 Peg 끝점–Hole 중심 상대 벡터의 오차다. 같은 ID 배정 입력에서 공간·시간 attention은 삽입 직전 횡방향 P90을 31.10 → 17.12 mm로 줄였다. 기존 63.60 mm의 가변 추적점 평가는 GT로 신원을 배정하지 않았고 입력 구성도 달랐다. 그 결과와의 차이는 Transformer만 교체했을 때의 효과로 해석할 수 없다. 이 평가에서는 GT ID가 주어진 조건의 좌표 복원 효과를 측정했으며, 현장 입력에서 GT 없이 동일한 ID를 유지하는 성능과 삽입 성공률은 별도 평가가 필요하다.

## 실행 검증 및 산출물

첫 수집 코드의 종료 조건을 수정해 레퍼런스상 200스텝에서 종료된 일부 궤적도 같은 상태로 재생했다. 첫 학습 시퀀스 길이 비교는 GPU 행렬 연산 정밀도에 민감했다. 학습은 같은 설정으로 다시 실행하고 인과성 검증에는 FP32와 동일 길이의 미래 관측 교란 검사를 적용했다. 전 수집·학습·평가를 공통 ExperimentLogger로 기록했다. 저장된 체크포인트의 해시, 데이터 분할, 최저 검증 오차 체크포인트, 관측 좌표의 정확한 보존, GT GNN 기준 예측 재현, 미검출점 P90을 검증했다. 학습과 GNN 추론은 CUDA에서 실행했고 다른 기기에서는 비교하지 않았다.
