# 검출 후보만 사용한 Peg·Box·Hole의 물리 꼭짓점 번호 배정

## 매칭 방식

[기존 Box 외곽 번호 배정 실험](box_corner_id_matching.md)을 재사용했다. 입력은 검출기가 반환한 3D 좌표, 물체 종류와 Hole 입구 후보 표식, 로봇 TCP 위치다. 현재 프레임의 확실한 대응만 관측 슬롯에 넣고 좌표는 RANSAC 후보 값을 그대로 보존한다.

- Box 외곽 8점은 기존 큐브 및 작업공간 각도 가정으로 번호를 배정한다.
- Hole 앞쪽 4점은 같은 Box의 좌표계로 변환한 뒤 앞면에서 검출기가 Hole 후보로 표시한 점으로 사각 입구를 초기화한다. 이후 Box 자세 변화에 따라 입구의 예상 꼭짓점을 이동시킨다.
- Peg 8점은 초기 Peg가 테이블에 수평으로 놓이고 양의 길이 축이 대체로 월드 +Y를 향한다는 조건에서 자세와 길이·폭을 초기화한다. 이후 직전 자세에서 검출 후보와 대응시키고 세 개 이상의 비공선 점이 확인되면 강체 회전을 갱신한다. 후보가 부족하면 회전을 유지하고 직전 속도 및 TCP 위치 변화로 다음 후보를 검토한다.

이 규칙으로 번호가 정해지지 않은 슬롯은 미검출로 남겨 기존 Transformer가 채운다. 이 구현은 Box가 회전하지 않고 평행이동하는 실험과 기존 초기 방향 범위를 사용한다. 대칭 물체에서 작업공간 제약이 사라지거나 장시간 전체 점이 가려질 때 같은 물리 번호가 유지되는지는 별도 검증이 필요하다.

## 저장된 RANSAC 후보 평가

기존 검증 24개(2,706프레임)와 테스트 32개(3,352프레임)의 원본 후보를 사용했다. 번호 추론에는 후보 좌표, 검출기 표식과 TCP만 통과시키고, GT 및 가시성 기반 대응은 출력 후 채점했다. 정밀도는 배정 좌표가 해당 번호 GT의 5 mm 이내인 비율이다. 재현율은 기존 GT 매칭으로도 대응 가능했던 가시 슬롯 중 번호를 되찾은 비율이다.

| 테스트 전체 3,352프레임 | 정확한 배정 / 전체 배정 | 대응 가능점 회수 | 다른 번호 |
| --- | ---: | ---: | ---: |
| Peg | 18,736/18,799 (99.66%) | 17,886/17,886 | 0 |
| Box 외곽 | 18,882/18,902 (99.89%) | 15,233/15,233 | 0 |
| Hole 입구 | 13,185/13,225 (99.70%) | 12,960/12,960 | 0 |

검증에서 Peg 번호가 다른 GT에 붙은 배정은 40건이며 시드 3100128의 20프레임에 집중됐다. Box 외곽과 Hole 입구의 번호 뒤바뀜은 검증에서도 0건이었다. Mac의 NumPy 매칭 부분만 측정한 지연 P95는 약 1.33 ms였다. 해당 자료는 삽입 직전에서 끝난다.

## 실제 RGB-D 재생으로 삽입 종료까지 확인

매칭을 기존 430에폭 후속 Transformer·28에폭 후속 GNN에 연결했다. 시드 3100176–3100183의 Expert 성공 데모 8개(고정 4개, 이동 4개)를 RTX 3090에서 끝까지 재생했다. 두 분기는 동일한 원본 검출 결과를 받았다. GT 없는 분기에는 segmentation을 제거한 RGB-D, 카메라 설정 및 관측 Robot TCP만 전달했고, 대조군에서만 이전 GT 기반 번호 배정을 수행했다. 학습된 가중치와 Box 강체 보정은 같다. Peg 끝점 기준 깊이 0 mm 이하, 0~20 mm, 20 mm 초과로 나눴다.

| 구간 | 프레임 | Object21 횡방향 P90, GT 번호 배정 | Object21 횡방향 P90, GT 없는 배정 |
| --- | ---: | ---: | ---: |
| 전체 | 1,069 | 3.92 mm | 3.96 mm |
| 삽입 전 | 959 | 3.76 mm | 3.67 mm |
| 얕은 진입 | 24 | 5.36 mm | 5.08 mm |
| 깊은 진입 | 86 | 4.44 mm | 4.56 mm |

| GT 없는 배정 | Peg 정확 / 배정 · 다른 번호 | Box 정확 / 배정 · 다른 번호 | Hole 정확 / 배정 · 다른 번호 |
| --- | ---: | ---: | ---: |
| 전체 | 5,625 / 5,661 · 4건 | 5,704 / 5,704 · 0건 | 3,637 / 3,663 · 0건 |
| 얕은 진입 | 106 / 124 · 4건 | 97 / 97 · 0건 | 3 / 6 · 0건 |
| 깊은 진입 | 302 / 302 · 0건 | 333 / 333 · 0건 | 7 / 17 · 0건 |

깊은 삽입에서 Hole 후보 10건은 다른 번호로 뒤바뀐 사례와 구분된다. 어느 GT 꼭짓점에도 5 mm 이내에 들지 않은 좌표가 Hole 슬롯에 들어갔다. 반면 그 구간에 GT 매칭으로 대응할 수 있었던 Hole 슬롯은 7건이며 모두 되찾았다. Expert 궤적의 소규모 비교에서 Object21 오차는 비슷했지만, Mamba 폐루프 성공률은 이번에 재평가하지 않았다.

재생 결과 파일은 정상 저장됐고, 종료 요약에서 NumPy 스칼라를 JSON에 기록하는 부분만 실패했다. 저장 원본의 해시와 각 데모의 연속 프레임 및 성공 종료 프레임을 확인해 별도 ExperimentLogger 실행으로 요약을 복구했다. 원래 실행 상태는 그대로 보존했다.
