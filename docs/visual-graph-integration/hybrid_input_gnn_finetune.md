# 검출·추적·강체 보정 좌표를 입력으로 한 Object21 GNN 파인튜닝

## 실험 조건

[강체 보정 연결 실험](spatiotemporal_rigid_box_eval.md)의 앞단을 고정하고 GNN만 학습했다. 원본 RANSAC 검출의 3D 좌표를 시뮬레이터의 가시 꼭짓점과 5 mm 이내에서 일대일 대응시켜 20개 물리 슬롯에 배정했다. 이 과정에서 GT로 입력 좌표를 교체하지 않았다. [954에폭 Transformer](spatiotemporal_corner_tracker_convergence.md)가 미검출 슬롯을 채웠고, 이전 관측이 있는 미검출 Box 외곽·Hole 슬롯에 기존 공통 평행 이동 보정을 적용했다. RANSAC 검출, Transformer, 강체 보정 모두 학습 중 고정했다.

GNN 입력은 최종 20개 좌표, 같은 시점의 TCP, 현재 검출 여부다. 입력 형식, 그래프 구성, 모델 구조, Object21 손실 및 AdamW 설정을 [고정·이동 GT 입력 학습](moving_box_gt20_training.md)과 동일하게 유지했다. 기존 GT 입력용 체크포인트를 초기 가중치로 사용했고, 학습 정답은 같은 프레임의 시뮬레이터 GT Object21이다. 번호 배정은 GT 기반이며, 실제 카메라만 쓴 전체 20점 번호 배정까지 검증하는 구성은 아니다.

학습 120개(13,448프레임), 검증 24개(2,706프레임), 테스트 32개(3,352프레임)를 시드 단위로 분리했다. Transformer 학습 때와 동일한 분할을 사용하므로 현재 GNN 학습 입력은 Transformer가 학습에서 봤던 장면을 기반으로 한다. 테스트 장면은 양쪽 모델의 가중치 업데이트 및 선택에 사용하지 않았다.

검증 손실이 이전 개선 기준에서 최소 0.5% 감소할 때마다 정체 계산을 초기화했다. 12에폭 동안 이 기준에 도달하지 못하면 학습률을 0.0003 → 0.0001 → 0.00003으로 낮췄다. 가장 낮은 학습률에서도 같은 기준으로 정체되면 종료하며, 한도는 240에폭이다. 검증 손실 최저 체크포인트와 마지막 에폭의 재개 상태를 별도로 저장했다.

## 입력 좌표 품질

| 데이터 분할 | 프레임당 관측 슬롯 평균 | 최종 20점 3D 오차 P90 | 미검출점 3D 오차 P90 |
| --- | ---: | ---: | ---: |
| 학습 120개 | 13.61 | 3.04 mm | 4.32 mm |
| 검증 24개 | 13.69 | 4.40 mm | 12.36 mm |
| 테스트 32개 | 13.75 | 3.53 mm | 6.37 mm |

관측점 수는 비슷했으나 분할별 미검출점의 입력 오차 규모가 달랐다. 검증 장면에서 미검출 Hole 점의 P90은 41.86 mm, 학습 장면에서는 6.54 mm였다. 학습 장면은 앞단 Transformer가 학습에서 이미 본 장면이고, 이 비교는 그 차이와 장면 자체의 난이도 차이를 분리하지 않는다.

## 학습과 종료

| 에폭 | 해당 에폭의 학습률 | 학습 손실 | 검증 손실 |
| ---: | ---: | ---: | ---: |
| 0 (GT 학습 가중치) | — | — | 0.28911 |
| 13 | 0.0003 | 0.03966 | 0.20002 |
| 27 | 0.0001 | 0.02648 | 0.19567 |
| 42 | 0.00003 | 0.02308 | 0.19426 |
| 54 (최저 검증 손실) | 0.00003 | 0.02292 | 0.19357 |

25에폭 이후와 39에폭 이후에 학습률을 낮췄다. 가장 낮은 학습률에서 42→54에폭의 추가 검증 손실 개선은 0.35%로, 사전에 정한 0.5%보다 작아 54에폭에서 종료했다. 54에폭 손실이 전체 최저이므로 이 체크포인트를 평가에 사용했다. 초기 체크포인트와 비교해 검증 손실은 33.0% 낮아졌다. 학습과 최종 테스트에는 RTX 3090에서 약 510초가 걸렸다.

## 동일 입력을 사용한 테스트 비교

두 GNN이 동일한 최종 20점, 관측 플래그, TCP를 사용했다. 테스트는 32개 장면 3,352프레임, 이동 중 695프레임, 삽입 직전 160프레임으로 집계했다. 횡방향은 Peg 끝점–Hole 중심 상대 벡터의 오차 중 GT 삽입축에 수직인 성분이다.

| Object21 지표 P90 | 기존 GT 입력 학습 GNN | 파인튜닝한 GNN |
| --- | ---: | ---: |
| 전체 횡방향 | 7.40 mm | 3.47 mm |
| Box 이동 중 횡방향 | 8.43 mm | 3.64 mm |
| 삽입 직전 횡방향 | 8.74 mm | 3.52 mm |
| 삽입 직전 Hole 중심 | 8.28 mm | 3.68 mm |
| 삽입 직전 Hole 삽입축 | 10.41° | 2.09° |
| 삽입 직전 Peg 끝점 | 5.18 mm | 4.35 mm |
| Box 이동 중 Peg 중심 | 3.87 mm | 4.05 mm |

삽입 직전 횡방향 P90은 입력 좌표를 고정한 상태에서 59.7% 낮아졌다. 이동 중 Peg 중심 P90은 소폭 커졌다. 이번 점수는 GT로 확인된 꼭짓점 번호와 매칭 좌표를 사용한 오프라인 결과다. GT 없이 자동으로 대응하는 경우의 Object21 오차와 실제 삽입 성공률은 별도 평가 범위다.

## 검증 및 산출물

공통 ExperimentLogger로 입력 캐시 생성과 학습을 기록하고 학습 루프와 손실을 재사용했다. 시드 단위 분할, 스크립트·가중치·입력 파일 해시, 기존 테스트 입력과 Object21 예측의 재현, 검증 손실 최저 체크포인트, 학습률 변경과 종료 조건을 확인했다. 저장된 예측으로 전체·이동 중·삽입 직전 횡방향 P90을 NumPy로 다시 계산했다. CUDA를 사용했으며 Apple MPS와 CPU 학습은 이 실험에서 실행하지 않았다.
